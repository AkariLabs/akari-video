# Scene3D カタログ

`assets/scene3d/` と同じ入庫基準（モデリング・質感・リグの生成コストが高い 3D 素材）の取得先索引です。実体は同梱せず、`source.url` から各自取得してください。

## エントリ

- [vintage-camera](./vintage-camera/meta.json) — 革ストラップと使用感のあるクラシックカメラの高精細 3D モデル（27K tri）。レトロ演出・製品紹介のヒーローショット向け。（license: CC0-1.0 / acquisition: direct）
- [studio-hdri](./studio-hdri/meta.json) — 柔らかい自然光ミックスのスタジオ HDRI（24K）。3D モデルへの環境光・反射付与に。（license: CC0-1.0 / acquisition: direct）
- [modern-smartphone](./modern-smartphone/meta.json) — 縁なしスクリーンの現代的なスマートフォン 3D モデル（4K テクスチャ）。画面差し込みモックアップ向け。（license: CC0-1.0 / acquisition: direct）
