# Introduction — AKARI Video とは

AKARI Video は、**AI エージェントが編集の主体になる**動画編集ツールです。

素材を渡すと、エージェントが分析・カット判断・テロップ・ナレーション・BGM を組み上げます。
人間の役割は 2 つだけ — **何を作りたいかを伝えること**と、**仕上がりが意図どおりかを確認すること**。
アプリは「編集する場所」ではなく「確認して直す場所」です。

## 3 つの原則

### 1. 開いたらほぼ終わっている

タイムラインをゼロから組む画面は用意しません。エージェントが仕上げた編集を開き、
気になるところだけドラッグと一言で直す。調整の 9 割はタイミングと配置なので、
それはデータ（`data-start` / `data-duration` / CSS 変数）の操作で完結します。
意図は人、手は AI です。

### 2. セーブデータがすべて（SSOT）

編集状態の正本は `edit.json` とオーバーレイ HTML 断片です。

- エージェントはツール呼び出しの積み重ねではなく、**セーブデータを直接読み書き**する。
  速く、壊れず、git diff で追える
- 人間の操作（ドラッグ・値変更・テキスト編集）も必ず同じデータに書き戻される。
  人間と AI が同じファイル上で衝突しない
- どの入口（ターミナル / opencode セッション / Claude Code セッション / アプリ)から触っても、同じファイル契約に収束する

### 3. 表現は固定の一覧から選ぶものではない

字幕・テロップ・図形・3D は、AI が HTML/CSS/Three.js で自由に描きます。
表現の受け口は事実上無限です。手元に残したスタイルやテンプレートは、
使い回したいときの近道であって上限ではありません。
そのかわりエンジン側の仕事は「時刻同期と合成」だけに絞ってあります。

エージェントは調整可能な値を **CSS 変数として宣言する**規約で書くため、
ビューワーはその変数を発見してツマミ（スライダーやカラーピッカー）を自動生成できます。
「AI が自由に描く」と「人間が GUI で微調整できる」は両立します。

すべては **headless-first** でもあります。各ステップはアプリなしで動く CLI コマンドかスキルで、
アプリは同じファイルを見るもう 1 つの入口です。

## アーキテクチャ概観 — サンドイッチ 3 層 + 手

```
┌─────────────────────────────────────────────┐
│ 表現プレーン（Web）                           │ ← 字幕・テロップ・図形・3D
│  HTML/CSS/SVG/Three.js、時刻同期              │    AI が書き、人間が触れる
├─────────────────────────────────────────────┤
│ 映像プレーン（ネイティブ）                     │ ← カットリストのギャップレス再生
│  サンプル精度同期・HW デコード                 │
├─────────────────────────────────────────────┤
│ 手（CLI）                                     │ ← ffmpeg / whisper.cpp /
│  カット・プロキシ・エンコード・書き出し          │    HyperFrames / 生成系 API
└─────────────────────────────────────────────┘
```

- **映像はネイティブに任せる** — カット境界のヒッチなし・4K HW デコード
- **表現は Web に寄せる** — LLM が最も得意な言語（HTML/CSS/Three.js）で描くから、プリセット不要
- **書き出しはフレーム正確** — プレビューはライブ DOM で即時、書き出しは同一 HTML を
  フレーム毎キャプチャで通すことで WYSIWYG を保証

設計の全体像と根拠は
[design-2026-07-13-agent-native-architecture.md](./design-2026-07-13-agent-native-architecture.md)
を参照してください。

## ワークフロー — ステージとスキル

制作の各段階はスキルとして独立しており、必要なところから使えます。

```
[開始]         akari new --from    作り方から、または白紙から
   ↓
[企画]         research-plan       ネタ出し → 調査 → 企画書 → 絵コンテ → 撮影リスト
   ↓
[素材分析]     analyze-footage     1 本ごとにプロキシ・文字起こし・キーフレーム抽出
               analyze-project     複数素材を読み合わせて解釈レポート
   ↓
[編集計画]     edit-plan           提案をタイムラインへ → プレビューで確認 → 書き出しの判子 1 回
               overlay-authoring   2D の動く部品: テロップ・字幕・図表・サムネイル
               author-scene3d      3D シーン（既定は Three.js / Blender で焼く経路も）
               generate-narration  ナレーション生成（ローカル無償 / 声クローン）
   ↓
[QA・レビュー] verify-edit         決定的 CLI 検査 + フレーム視認
               review-from-recording / edit-from-review   口頭レビュー → チケット → 対応
   ↓
[書き出し]     render-cut          計画 → 承認 → レンダリング → 検証
   ↓
[素材化]       harvest-asset       成果物をライブラリへ入庫
               record-playbook     この動画の作り方を「作り方」として残す
```

各ステージの節目は `.akari/events/` に 1 件ずつ記録され、次にセッションを開いたとき
「続きから」が自動で案内されます。

## 1 本ができるまで

以下は画面に出る語です。どれも「選んだ後に何ができるか」で名前を付けています。

- **素材** — 足して、ツマミで変えるもの。映像・画像・音・3D・動く部品・フォント・自分で撮った映像。
- **スタイル** — 当てるもの。文字の見た目・字幕スタイル・LUT・つなぎ・動き。気に入ったものは「<!-- F ui.library.myStyles -->自分のスタイル<!-- /F -->」に残せます。
- **テンプレート** — 尺・文字・枠・音が決まったまとまり。ライブラリからタイムラインへ落とし、枠に自分の映像を入れて使います。
- **作り方** — 完成した 1 本の手順・確認点・設定・仮枠。気に入ったプロジェクトから記録し、
  そこから新しいプロジェクトを始められます（`akari new --from`、またはホームの「作り方から」）。
  読むための計画なので、黙って何かが適用されることはありません。

そのまわりで、アプリの次の部分が仕事の大半を受け持ちます。

- **ホームとプロジェクトパネル。** ホームは最近のプロジェクトの一覧と、白紙から / 作り方からの開始。
  左のプロジェクトパネルは、素材（種別で絞れる）・記録・出力の 3 帯です。
- **注釈。** プレビューの上に、ペン・ピン・範囲・添付で直接書き込めます。メモは右パネルに集まり、
  AI に渡せる形で `review.json` に保存されます。
- **台本パネルとタイムライン。** タイムラインの最上段が台本です。字幕の見た目は「字幕全体」か「選んだ文字だけ」に当てられます。
- **シーン。** プロジェクトはシーンを持てます。シーン / 構成 / 関係のタブで部品のつながりを見渡せ、
  依存の目録は `.akari/manifest.json` が持ちます（`akari project sync` / `check` / `scene add`）。
- **AI パートナー。** アプリは、いつも使っているエージェントをそのまま動かします。
  Claude Code と Codex が推しの 2 つで、opencode・Cursor Agent・Muse Code CLI も使えます。
  これらの CLI エージェントは設定から更新できます。
- **Lab。** 素材・スタイル・テンプレートの追加は Lab から。無料（CC0）と Pro の 2 階層で、
  `akari store connect` で連携します。

## 判子は書き出しの 1 回

既定は**提案つき**（`checkpoint`）。頼まれた物に加えて良さそうな物もタイムラインに入れて見せ、
途中の承認はありません。プレビューで見て、要らなければ消す・直す・出す。
押す判子は書き出しの 1 回だけです。

**そのまま**（`full-auto`）は言った通りに入れて見ずに書き出し、判子は 0 回です。
出た後に capture 1〜2 枚と lint 結果を `.akari/reports/` に添えます。

**一緒に作る**（`collaborative`）だけは、方針 → 素材計画 → 実行の 3 段階で確認し、段階ごとに判子を押します。

切り替えは進め方フォーム（`.akari/intake.json` の `autonomy`）です。ホームの「今回の進め方」にある「おまかせの度合い」で選べます。

課金と外部送信の承認はモードと独立です。`connections.json` のコスト承認ポリシーが優先されます
（[接続と API キー](./how-to/connections.ja.md)）。

スキルは Claude Code プラグイン・opencode・Cursor Agent・Codex から自動で見つかります。
全 29 本は[スキルカタログ](./skills.ja.md)を参照してください。
