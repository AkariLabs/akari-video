# FAQ・トラブルシューティング

## 全般

**Q. アプリが無いと使えない？**
いいえ。headless-first 設計なので、opencode や Claude Code だけで企画から書き出しまで完結します。
アプリ（Theia シェル）は主な入口で「確認して直す場所」です。パートナー欄でエージェントを動かすこともできます。

**Q. 完全自動で最後まで走らせられる？**
既定の**提案つき**（`checkpoint`）では途中の承認はなく、書き出しが唯一の判子です。
`full-auto`（そのまま）は書き出しも見ずに行い、`collaborative`（一緒に作る）は
方針 → 素材計画 → 実行の 3 段階で確認します。
**課金と外部送信**の承認はこれと独立で、`connections.json` のコスト承認ポリシーが優先されます。

**Q. 外部 API なしでどこまでできる？**
プロキシ生成・文字起こし（whisper.cpp / macOS SpeechAnalyzer）・編集・テロップ・
VOICEVOX ナレーション・lint・書き出しまで、ローカル無償で一周できます。

**Q. Windows は？**
Windows に対応しています。デスクトップアプリ（インストーラの `.exe` または `.zip`）と
`akari` CLI があります。詳細は [dev/windows-build.md](../dev/windows-build.md) を参照。

**Q. Windows でインストーラを起動すると SmartScreen の警告が出る**
Windows 版のインストーラはまだコード署名されていないため、初回の起動で SmartScreen が
警告することがあります。公式のリリースページから入手したものなら、「詳細情報」→「実行」で
進めてください。macOS 版は Developer ID で署名され、Apple の公証を受けています。

**Q. 安定版とベータ版はどう切り替える？**
設定 › このアプリについて › **受け取る版** です。既定は**安定版だけ**で、**プレリリースも**に
すると新しい機能を早く試せるベータ版も届きます。安定版に留まりたいときは「安定版だけ」に戻します。

**Q. ドキュメントの画面の語やコマンド名が、手元のアプリと違う**
v1.5.0 のビルドは語の差し替えの前に作られたため、画面や一部のコマンドが旧い名前のままです。
次の版で新しい名前になります。旧いコマンド名は別名として残ります。

| ドキュメント（新） | v1.5.0 のアプリ（旧） |
|---|---|
| 動く部品 | オーバーレイ |
| 自分のスタイル | マイスタイル・保存したプリセット |
| 字幕スタイル | 字幕テンプレ |
| チャンネルの設定 | ブランドキット |
| 3D の設定 | 3D レシピ |
| ライブラリの「テンプレート」の棚 | 「ひな形」「セット」のタイル |
| `akari new --scaffold` | `akari new --template` |
| `akari template export` | `akari playbook template` |

**Q. アプリの言語を変えられる？**
変えられます。設定 › 表示 › **言語** › 表示する言語で、自動（OS に合わせる）・日本語・English を
選びます。切り替えるとウィンドウを再読み込みします。

**Q. AKARI チャットが見当たらない**
AKARI チャット（お試し）は既定では隠れています。設定 › パートナー の
「AKARI チャット（お試し）を表示する」をオンにしてください。ふだんの作業には Claude Code や
Codex などのパートナーをつなぎます（[接続と API キー](./connections.ja.md)）。

## 作り方・テンプレート・Lab

**Q. 作り方とテンプレートは何が違う？**
**作り方**は「読むもの」です。1 本ぶんの手順・確認点・設定・仮枠で、素材は持ちません。
ホームの「＋ 新しい動画を始める」→「作り方から」、または `akari new <dir> --from <作り方>` で始めます。
**テンプレート**はタイムラインに「置くもの」です。尺・文字・枠・音が決まったまとまりで、
仮枠に映像を差し替えるだけで使えます。テンプレートは作り方を 1 段深くしたものです。

**Q. ライブラリの「テンプレート」の棚が空**
同梱のテンプレートはありません。追加するまでは「テンプレートはまだありません」と出ます。
自分の動画のまとまり（グループ）1 つを
`akari template export <プロジェクト> --item <まとまりの項目 id> --id <テンプレート id>`
で書き出すと、棚に並びます。`akari template list` で一覧できます。

**Q. Lab の無料と Pro は何が違う？**
Lab は無料と Pro の 2 階層です。無料の素材は CC0 で、アカウントを連携すると使えます。
Pro の素材は購入や権利に応じて解錠され、AKARI の素材ライセンスが付きます（各パックに
`LICENSE.md` が入っています）。アカウントの連携は `akari store connect` です
（[詳しく](./connections.ja.md)）。

**Q. 字幕の見た目を、全体にも一部の語にも当てたい**
台本パネルで、字幕スタイルを**字幕全体**に当てられます。語を選んで**選んだ文字だけ**を
押すと、その語にだけ当たります。字幕全体に当てても字幕の大きさは変わりません。語ごとの見た目は
「字幕全体の見た目に戻す」で戻せます。前の形の字幕が残るプロジェクトでは、見た目を固定することを
1 回だけおすすめします。ターミナルからは `akari captions migrate-look <project> [--dry-run]` です。

## 文字起こしと書き出し

**Q. 文字起こしはどのエンジンで動く？**
既定は自動です。macOS ではローカルの SpeechAnalyzer を使い、使えないときは whisper.cpp に
切り替えます（ほかの OS では whisper.cpp がローカルのエンジンです）。whisper.cpp のモデルが
まだないときは `akari tools install whisper`（または 設定 › 道具 › Whisper）で取得します。
クラウド（ElevenLabs Scribe・Groq）は鍵を設定したときだけ使い、送る先と費用の目安を先に出します。
明示するなら `--backend <speech-analyzer|whisper-cpp|cloud:<id>>` です。

**Q. 書き出しはどのエンジンで動く？**
既定の `--engine auto` は、素材と効果が条件を満たし、GPU にハードウェアエンコーダがあれば
速い GPU の経路を使い、それ以外は OSR（Electron のオフスクリーン描画）を使います。
OSR になったときは書き出しの画面に理由が出ます。`--engine gpu` は条件を満たさないと理由つきで止まり、
`--engine osr` は常に使えます。

## 編集・データ

**Q. edit.json を手で編集していい？**
構いません。テキストなので直接編集も git 管理もできます。編集後は
[edit-lint](../guides/review-and-fix.ja.md) をかけてください。

**Q. カットを並び替えたら字幕や注釈がズレない？**
ズレません。時刻は常に (素材, 素材の原本秒) で永続化する規約で、
タイムライン位置に依存しません。

**Q. 前の状態に戻したい**
プロジェクトを git 管理していれば、セーブデータはすべてテキストなので
`git diff` / revert がそのまま「編集履歴」になります。

## エラー対処

**Q. チャットが途中で切れます**
パートナーを「拡張」形態（Claude Code 拡張 / Codex 拡張）で使っている場合、
拡張ホストが再起動すると会話が切れます。長い作業には CLI 形態をおすすめします
（パートナー欄で「推奨」が付いている `Claude Code CLI` は PTY タブなので巻き込まれません）。
切れた後は、パートナー欄で `/akari` と打つと今の状況から続けられます。
ターミナルからは `akari --continue` です。詳細は
[続きから再開する](./resume-session.ja.md)。

**Q. edit-lint が FAIL する**
`.akari/reports/edit-lint-report.html` に件数と理由が出ます。
「lint の FAIL を直して」で対応まで頼めます。FAIL のままでは書き出しに進めません。

**Q. render-cut の verify が FAIL する**
`.akari/reports/render-report.html` の stderr 要約を確認してください。
「render の失敗を調べて」で診断から頼めます。

**Q. ffmpeg / whisper / Blender が無いと言われる**
各スキルが検出時に導入手順を案内します。まとめて確認したいときは
「セットアップの状態を確認して」（setup-library のツールチェック）か `akari doctor`。
whisper のモデルは `akari tools install whisper` で取得できます。

**Q. API キーを設定したのに使えない**
「doctor かけて」で疎通診断を。キーの実体は `~/.akari/credentials.env`
（旧い場所の `~/.config/akari-video/credentials.env` も読みます）、
プロジェクト内には参照だけ、が正しい配置です。設定 › つなぐ で、どのサービスが使えるか見られます。

**Q. プロジェクトの開きが遅い・ホームが重い**
v1.4.1 以降に更新してください。以前の版は保存のたびに全部のプロジェクトを読み直していたため、
プロジェクトが多いとホームや一覧が重くなっていました。いまは変わったプロジェクトだけを、
一覧が見えているときに読みます。古い形式の `edit.json` は `akari migrate [dir]` でバックアップを
残して v2 へ変換できます。それでも開かないときは `akari doctor` をかけ、
`.akari/reports/` のレポートを添えて GitHub Issues へ。

**Q. `apps/shell` を自前ビルドした後、`npm start` がウィンドウを出さずに無言終了する（Apple Silicon）**
`apps/shell` のビルドが Electron.app 内蔵の ffmpeg ライブラリを差し替える際にコード署名を壊すことがあります。
`npm run build` は完了後に自動でアドホック再署名（`postbuild`）するため通常は発生しませんが、
再発した場合は手動で次を実行してください: `codesign --force --deep --sign - node_modules/electron/dist/Electron.app`。
