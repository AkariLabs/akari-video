# シェル UI: 素材とタイムライン

デスクトップシェルは「ゼロから組む場所」ではなく「確認して直す場所」ですが、
頻出の直しにはマウスの直行ルートがあります。このページは素材パネルと
タイムライン周りの操作をまとめます。

## 素材パネル: 右クリックメニュー

素材カード（未整理を含む）や「できたもの」行（編集データ / 企画メモ / 書き出し /
レポート）を右クリックすると:

- **開く** / **Finder で表示** / **ファイルをコピー**（macOS のみ） / **パスをコピー**
- **タイムラインに追加**（video / audio 素材）— 再生ヘッド位置へ挿入
- **素材の情報を表示**（`assets/` 配下の素材）
- **名前を変更** / **削除** — どちらも先に `edit.json` / `captions.json` への参照
  チェックが走り、削除はゴミ箱行き
- **エージェントに頼む** — 接続中のパートナーエージェントへファイルを渡す
- **assets へ移動**（未整理のみ）

破壊操作（名前変更 / 削除）と「エージェントに頼む」は素材・未整理・書き出しに
限定され、データ / 企画 / レポート行は開く系のみです。

## タイムラインへのドラッグ & ドロップ

素材カードをタイムラインへドラッグすると配置できます。ドラッグ中は尺ゴーストで
置かれる範囲が見え、置き先のトラックを選べます。動画・画像素材は `layers[]` へ、
音声は `audio.sfx[]` へ入ります。

## タイムライン: クリップの右クリックメニュー

クリップを右クリックすると **コピー / ペースト / 分割 / 削除**。既存のキーボード
操作と同じハンドラをメニューとして呼び出したものです。

## すべてセーブデータに着地する

これらの操作はすべて、エージェントが読み書きするのと同じファイル契約
（`edit.json` ほか）への書き込みです。UI だけの状態はありません — マウスでやった
ことは会話で続きから直せ、その逆も成り立ちます。
