# シェル UI

デスクトップアプリ（シェル）は「ゼロから組む場所」ではなく「確認して直す場所」です。
AI パートナーが作ったものを見て、ドラッグや右クリックで直せるようにしてあります。
このページは v1.5.0 時点の画面を、ホーム → 左のパネル → ライブラリ → プレビュー →
右のパネル → タイムライン → 台本 → 設定の順に案内します。

画面の左端の列は「プロジェクト / ライブラリ / スキル / つなぐ / 書き出し / チャンネル / 設定」です。
右端の列には「パートナー / インスペクター / 台本 / 注釈」などのパネルが並びます。
上の帯には「チャンネル › プロジェクト」の場所、5 段の進み具合、保存済みかどうかが出ます。

## ホーム

- **ホーム**には過去のプロジェクトが新しい順に並びます。開くときは「この画面で開く / 新しいウィンドウで開く」を選べます。パートナーが作業中なら、終わってから開くこともできます
- **<!-- F ui.home.startButton -->＋ 新しい動画を始める<!-- /F -->**で開く「<!-- F ui.home.newProjectHeading -->新しいプロジェクト<!-- /F -->」は 1 枚のポップアップです。名前とチャンネルを決め、「白紙から」か「作り方から」を選びます。チャンネルに入れずに作ることもできます
- 「作り方から」は、手元・チャンネル・Lab の作り方をカテゴリーと入手先で絞って選びます。選ぶと確認シートが出て、何が入るか・要る道具がそろっているかが分かります。「取り込んで始める」で、仮枠の入ったプロジェクトができます
- 作ったばかりのプロジェクトのホームには「どこから始めますか」が出ます。「型から」「素材から」「話して」の 3 つです
- プロジェクトのホームでは、名前をその場で変えられます。「履歴」と「やったこと」から、エージェントが進めた作業を見て戻せます。公開・提出・有償の生成・外部への送信・元素材の削除のような戻せないことだけは、エージェントが止まって「承認 / やめる」を聞きます
- 初めて使うときは「はじめてのガイド」が案内します。あとから「はじめてのガイドをもう一度」でやり直せます

## 左のプロジェクトパネル

左のパネルの上に「プロジェクト / ライブラリ」の切り替えがあります。プロジェクトの面は 3 つの帯です。

- **素材**: このプロジェクトに入れたものです。サムネイルのカードと、動画のコマ・音の波形の帯のリストを切り替えられます。左上の漏斗から種別で絞ります。すべて / 映像 / 画像 / 音声 / 3D の設定 / 仮枠 / ほか（3D・HTML・フォント…）で、各行に件数が出ます。仮枠を押すと、タイムラインのその枠が選ばれます。並べ替えと検索もあり、右下の ＋ からパソコンのファイルを取り込めます
- **記録**: 企画・編集データ・レポートが並びます
- **出力**: 書き出したもの。細い帯で、新しい順に 3 件までです。上端をドラッグして高さを変えられます。「開く」「Finder で表示」がその場でできます

素材カード（未整理を含む）や記録の行を右クリックすると、次が出ます。

- **開く** / **Finder で表示** / **ファイルをコピー**（macOS のみ） / **パスをコピー**
- **タイムラインに追加**（映像・音声の素材）— 再生ヘッド位置へ挿入
- **素材の情報を表示**（`assets/` 配下の素材）
- **文字起こし**（映像・音声の素材）— ステップのポップアップで進み具合が見え、途中で中止できます
- **名前を変更** / **削除** — どちらも先に `edit.json` / `captions.json` への参照チェックが走り、削除はゴミ箱行きです
- **エージェントに頼む** — 接続中のパートナーへファイルを渡します
- **ライブラリに保管**（プロジェクト内の実体の素材）— ライブラリの置き場へ複製します。プロジェクト側のファイルと `edit.json` は変わりません
- **assets へ移動**（未整理のみ）

名前変更・削除・「エージェントに頼む」は素材・未整理・書き出しに限られ、編集データ・企画・レポートの行は開く系だけです。

素材のパネルや中央の素材プレビューでは、使う範囲（in / out、I / O キー）を決められます。タイムラインへ置くと、その範囲だけが入ります。

## ライブラリ

ライブラリは、タイムラインへ落とす物の棚が 1 つです。分類は「何か」で決まり、種類は絞り込みで選びます。

- **素材の分類**: BGM・SFX・B-roll・画像・<!-- F ui.library.motionParts -->動く部品<!-- /F -->・3D・アバター、フォント、図形。タイル（またはカード）を押すと一覧が開き、タイムラインへドラッグするか右クリックで置けます
- **スタイル**: <!-- F ui.library.captionStyle -->字幕スタイル<!-- /F -->・テキストアニメ・LUT・トランジション。選んだ文字やカット境界へ当てます。ホバーで見本が再生されます
- **<!-- F ui.library.myStyles -->自分のスタイル<!-- /F -->**: 文字・字幕の今の見た目を「自分のスタイルに保存」でき、あとから当てられます。名前の変更と削除ができます
- **<!-- F ui.library.motionParts -->動く部品<!-- /F -->**: HTML の動く素材です（旧称はオーバーレイ）
- **「テンプレート」の棚**: ライブラリの下にあります。手元・チャンネル・Lab のテンプレートが「テンプレート」の印つきで並び、まだ無いときは書き出し方の案内が出ます
- **キットからまとめて入れる**: 「詳細」を開いた「素材」のグループにあります。キットの中の素材を、まとめて取り込めます
- **<!-- F ui.library.channelSettings -->チャンネルの設定<!-- /F -->**: 「詳細」の「マイ」にあります

検索欄の右の **絞り込み**は 1 つのボタンです。出どころ（全部 / 自分の / 素材サイト / Lab）・tier（無料 / Pro）・ライセンス（商用 OK / 帰属表示あり / 商用不可）・状態（取得済み / 未取得 / ★）で絞ります。Pro 素材は鍵つきで表示されます。0 件のカテゴリは薄く表示されますが、開けます。

ホームの **最近入れた・よく使う**には、自分で入れた素材と素材サイトの素材が並びます。同じフォルダの素材は 1 個にまとまり、押すとそのフォルダに絞れます。

### 入れる

- **ローカルから**: 右下の **＋ → ローカルから取り込む**で選ぶか、**ライブラリの面へドロップ**します。取り込み前のシートで種類と件数を確認し、迷った音は効果音 / BGM を選べます。対応外のファイルと重複は、理由とともに分けて出ます。動画・音・画像・フォントはまとめて落とせます
- **フォント**: 取り込むとすぐ使え、書体の名前で並びます。「テキスト › フォント」に出ます。フォントのカードから「場所を見る」「ライブラリから消す」ができます
- **素材サイトでさがす**: ＋ → 素材サイトでさがす。掲載サイトを中央のタブで開き、検索と試聴はサイト自身の画面で行います。ダウンロードのリンクは利用者が押します。受け取ったら「ライブラリに入れる / 捨てる」を選びます。AKARI のおすすめは配布ページを開いてダウンロードの場所に枠を付けますが、押すのは代行しません。サブスク由来の素材には「サブスク」の札が付きます
- **Lab から**: ＋ から Lab を開いて入れます。アプリとの連携は `akari store connect` で行います。作り方は `akari store install <id>` でも入れられます
- **出どころの印**: カードには自分の / Lab / 同梱の出どころが付きます

## 真ん中のプレビュー

出力プレビューは、タイムラインを実際に再生して見る面です。

- **選ぶ・動かす**: クリックで要素を選び、ドラッグか矢印キーで動かします。辺や角のハンドルで大きさ、回転のハンドルで向きを変えます。選択枠は見えている中身に合います。HTML の素材は中の要素も選べます（元のファイルは書き換えず、変えた分だけがプロジェクトに残ります）。テロップはクリックで全体を選び、文字の上のダブルクリックで文字の編集に入ります
- **キーフレーム**: 位置・大きさ・回転を変えると、選択の上の「◆ キーを打つ」でその時刻にキーを打てます
- **3D**: 3D の部品はインスペクターに「3D」の節が出て、回転を数値で変えられます。プレビューでは本体を押して移動し、色のリングで回します。素材の動画や画像を 3D の上に落とすと、その画面に映ります
- **印を付けて AI に渡す**: 再生バーの 2 行目に **ペン・ピン・範囲・添付**が並びます。気になる所に印を付けてメモを書くと、そこにある字幕や映像も一緒に記録され、確定すると右パネルの**注釈**になります。置いたピンはドラッグで動かせます。メモ欄と添付の一覧は、再生・シークしたまま出しておける小窓です
- シークしたときの音（スクラブ音）は、設定の「プレビュー品質」でオンにできます。既定はオフです

## 右のパネル

- **インスペクター**: 選んだものの設定が並びます。文字（フォント・大きさ・色）、色、動き、3D など。トランジションを選ぶと、種類・向き・長さ・位置を変えたり「なし」にしたりできます。キーフレームもここで扱います
- **注釈**: プレビューで付けた印と録音が、上から順に読める並びで出ます。1 件ずつでも、まとめてでも **<!-- F ui.annotation.handToAi -->AI に渡す<!-- /F -->**ことができ、パートナーの入力欄に依頼文が入ったところで止まります。ペンの線は「どこからどこへ」が依頼文に入ります。注釈と録音は削除できます
- **パートナー**: AI パートナー（Claude Code・Codex・opencode・Cursor Agent・Muse Code ほか）が動く場所です。開いているプロジェクトが作業対象になり、最後に使ったパートナーが自動で開きます

## タイムライン

- **台本の段**: 一番上の段です。作り方の予定は帯、メモは点の印で並び、押すとその時刻へ移動します
- **左の列**: トラックの名前と操作です。境目をドラッグすると幅を変えられ、次回も同じ幅になります。切れた名前に乗せると全文が出て、どの行にも種類のアイコンが付きます
- **クリップの右クリック**: **コピー / ペースト / 分割 / 削除**。キーボード操作と同じものです
- **素材をドラッグ & ドロップ**: 素材カードをタイムラインへドラッグすると、尺ゴーストで置かれる範囲が見え、置き先のトラックを選べます。映像・画像は落とした行に応じて `layers[]`（重ねる映像）か `cuts`（本編カット）へ、音声は `audio.sfx[]` へ入ります。既存のクリップと重なるときは、映像・画像はその行のすぐ上、音はすぐ下に新しいトラックを作って置きます。確定時に実尺で再判定し、新しいトラックと素材の追加は 1 回の取り消しで戻ります
- **Finder からドロップ**: 動画ファイルは `assets/` へ取り込まれてから、落とした位置と行に置かれます。タイムラインの外（パネル・ホーム）へ落とすと取り込みだけです
- **吸着**: 物を動かすときの吸着は、どの物どうしでも同じです
- **トランジション**: クリップのつなぎ目に「+」が出ます。押すと見本つきの選ぶ画面が開きます。ライブラリのカードをドラッグしても付けられます。付けられないつなぎ目は薄い「+」で、押すと理由が出ます。素材の余りが足りないときは、余りのある側へ寄せ、それでも足りなければ **止め絵で埋めて付け**られます（付ける前に確かめが出て、止め絵の区間は帯に斜線で示します）
- **テンプレートを置く**: 「テンプレート」の棚からタイムラインへドラッグすると、まとまり 1 つとして置けます。中で使う素材も入り、取り消し 1 回で素材ごと戻ります
- **空き枠に落として差し替える**: 空いている枠（仮枠）へ素材を落とすと、枠の尺のまま中身が入れ替わります。種類が違うときは「この種類の素材は仮枠に入りません。」と出ます
- **取り消し**: 元に戻す・やり直しは、アプリでの編集に効きます。アプリで編集している間に AI が同じ編集を書き換えていたら、黙って上書きせず、読み直してお知らせします

## 台本パネル

台本パネルには、文字起こしの行が素材ファイルごとのまとまりで並びます（見出しを押すと開き、「すべて開く」もあります）。

- **予定とメモの行**: 作り方の予定（「0:00–0:03 つかみ: …」のような区間）とメモが、時刻の順に一緒に並びます。予定は済んだらチェックでき、「＋ メモ」で今の再生位置にメモを足せます。「表示」から「予定とメモを出す」を外すと字幕だけの台本に戻ります。行を押すとその時刻へ移動します
- **<!-- F ui.library.captionStyle -->字幕スタイル<!-- /F -->**: 語を選んで字幕スタイルを当てます。**字幕全体**に当てても字幕の大きさは変わりません。**選んだ文字だけ**に当てることもでき、プレビューでは選んだ文字が点線の枠で示されます。「字幕全体の見た目に戻す」で戻せます
- **話者**: 話者を分けた字幕には、話者の札が付きます。人物につなげたり、名前を付けたりできます。「話者で絞る」で 1 人の行だけを表示できます
- 行の 🎙 から、その行の頭から読む文を見ながらアフレコを録れます

## シーンを持つプロジェクト

長い作品は、1 つのプロジェクトの中をシーンに分けて作れます。

- シーンを持つプロジェクトを開くと、シーンの一覧が出ます。「＋ シーンを足す」で足せます
- シーンを開くと、上の帯が「チャンネル › プロジェクト › シーン ▾」になり、▾ からほかのシーンへ移れます
- 一覧のページには **シーン / 構成 / 関係**のタブがあります。構成はプロジェクト → シーン → カットの木で、尺・仮枠の数・字幕と書き出しの有無が分かります。関係は素材・スタイル・人物・文書のつながりの図で、欠けているものと古いものは点線で示します
- 欠けや未取得があるときは、画面の上に「欠落 1・未取得 1」のような帯が出ます
- プロジェクト全体で使う素材は、シーンの素材の一覧に「共通」の印で出ます。シーンの中からは名前の変更や削除ができません

## 設定

左端の「設定」を開くと、左に 6 つの柱が並びます。柱を選ぶと中の項目が右に 1 本のページで並び、真ん中の目次から項目へ移れます。

- **一般**: AKARI アカウント、はじめてのガイド、困ったとき、このアプリについて。「受け取る版」はこの中にあります（既定は「<!-- F ui.settings.stableOnly -->安定版だけ<!-- /F -->」。「<!-- F ui.settings.prereleaseToo -->プレリリースも<!-- /F -->」を選ぶとベータ版も届きます）
- **パートナー**: 一緒に作業する AI。それぞれ「今の版 · 最新の版」が出て、新しい版があれば「アップデート」で上げられます。「AKARI チャット（お試し）を表示する」もここです（既定は非表示）
- **つなぐ**: 外部サービスの接続と鍵、AI モデル、読み上げ、文字起こし、書き出しの既定値。鍵はサービスのカードごとに入れ、状態は「使える」「鍵が必要」で分かります。鍵は末尾 4 文字だけが表示されます
- **進め方と上限**: プレビュー品質（シーク時の音のオン / オフを含む）、通知、道具
- **表示**: 外観（色・表示する言語。自動 / 日本語 / English）とショートカット
- **データの場所**: ストレージ（AKARI が使っているディスクの量）と、プライバシーとアクセス許可

## すべてセーブデータに着地する

ここまでの操作はすべて、エージェントが読み書きするのと同じファイル契約への書き込みです。
編集は `edit.json`、プレビューの注釈は `review.json`、字幕は `captions.json`、
プロジェクトの目録は `.akari/manifest.json` に入ります。UI だけの状態はありません。
マウスでやったことは会話で続きから直せ、その逆も成り立ちます。
