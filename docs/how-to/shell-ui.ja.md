# シェル UI: 素材とタイムライン

デスクトップシェルは「ゼロから組む場所」ではなく「確認して直す場所」ですが、
頻出の直しにはマウスの直行ルートがあります。このページは素材パネルと
タイムライン周りの操作をまとめます。

## 素材パネル: 右クリックメニュー

素材カード（未整理を含む）や「できたもの」行（編集データ / 企画メモ / 書き出し /
レポート）を右クリックすると:

- **開く** / **Finder で表示** / **ファイルをコピー**（macOS のみ） / **パスをコピー**
- **タイムラインに追加**（video / audio 素材）— 再生ヘッド位置へ挿入
- **素材の情報を表示**（`assets/` 配下の素材）
- **文字起こし**（video / audio 素材）— ステップのポップアップが開き、進み具合が見えて途中で中止できます
- **名前を変更** / **削除** — どちらも先に `edit.json` / `captions.json` への参照
  チェックが走り、削除はゴミ箱行き
- **エージェントに頼む** — 接続中のパートナーエージェントへファイルを渡す
- **assets へ移動**（未整理のみ）

破壊操作（名前変更 / 削除）と「エージェントに頼む」は素材・未整理・書き出しに
限定され、データ / 企画 / レポート行は開く系のみです。

## ライブラリ: 出どころと最近の素材

検索欄の上の **全部 / 自分の / 素材サイト / Lab** で出どころを絞れます。
ホームの件数とカテゴリ内の一覧に同じ条件が効き、ホームへ戻っても選択が残ります。
0 件のカテゴリは薄く表示されますが、開けます。テキストスタイル・テキストアニメ・
LUT・トランジションは Lab に含まれます。

ホームの **最近入れた** には、自分で入れた素材と素材サイトの素材が新しい順に最大 8 件並びます。
同じフォルダの素材は 1 個にまとまり、押すとカテゴリ内でそのフォルダに絞れます。
フォルダ名の横の × で絞り込みを解除できます。個別の素材を押すと、そのカードが示されます。

置き場の素材も通常のカードとして表示され、音源は試聴できます。
外部サイトの索引カードは「素材サイト」に含まれ、
従来どおり「取り込む」「頼む」から操作できます。

## タイムラインへのドラッグ & ドロップ

素材カードをタイムラインへドラッグすると配置できます。ドラッグ中は尺ゴーストで
置かれる範囲が見え、置き先のトラックを選べます。動画・画像素材は落とした行に応じて
`layers[]`（重ねる映像）または `cuts`（本編カット）へ、音声は `audio.sfx[]` へ入ります。

素材が置き先の既存クリップと重なる場合は、映像・画像はその行のすぐ上、音はすぐ下に新しいトラックを作って置き、ドラッグ中も挿入線と案内文で表示します。
確定時には実尺で再判定し、新しいトラックと素材の追加をまとめて1回の Undo で取り消せます。

**Finder から直接タイムラインへドロップ**することもできます。動画ファイルはまず
`assets/` へ取り込まれ、続けて落とした位置・落とした行へ置かれます。タイムラインの外
（素材パネル・ホーム）へ落とした場合は取り込みだけが行われ、そのあと素材カードを
右クリック →「タイムラインに追加」で置けます。

## タイムライン: クリップの右クリックメニュー

クリップを右クリックすると **コピー / ペースト / 分割 / 削除**。既存のキーボード
操作と同じハンドラをメニューとして呼び出したものです。

## すべてセーブデータに着地する

これらの操作はすべて、エージェントが読み書きするのと同じファイル契約
（`edit.json` ほか）への書き込みです。UI だけの状態はありません — マウスでやった
ことは会話で続きから直せ、その逆も成り立ちます。
