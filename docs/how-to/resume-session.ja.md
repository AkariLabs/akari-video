# 続きから再開する

AKARI Video は「セッションをまたいでも文脈が戻る」ことを設計に組み込んでいます。
状態はすべてプロジェクトのファイルにあるので、どの入口からでも同じ続きから始められます。
Claude Code のプラグインには、セッションを開いた瞬間に続きを渡す仕掛け（SessionStart hook）もあります。

## 仕組み

各ステージの節目（レポート生成・承認・編集完了・書き出し完了など）と、エージェントの
「やったこと」・確認待ちは `.akari/events/` に 1 件ずつ記録されます。

プラグインを有効化していると、プロジェクトのディレクトリで Claude Code セッションを
開いた瞬間に SessionStart hook が:

1. `.akari/` を自動検知
2. 進め方フォーム（やること / 尺 / おまかせ度）・素材・分析・注釈・チェック・書き出し・承認の
   状態と節目の記録から、今の段階を判定
3. 「次のスキル」と「待っていること」を状態として自動注入

します。たとえば素材の分析が済んでいなければ分析、注釈が開いたままなら注釈の対応、というように、
ファイルの状態から続きが決まります。作業場（`.akari/root.json` のあるフォルダ）で開いたときは、
作業場の状態を渡します。

`.akari/` が無いディレクトリでは何もしません（通常のセッションを邪魔しない）。

## 手動で状態を確認する

- セッション内: **`/akari`** — 状態診断 + 次の一手の案内
- ターミナル: **`akari`**（引数なし）— プロジェクトを開いて診断してから AI エージェントを起動
  （未作成なら自動で作成）。`akari --continue` のように渡した引数は Claude Code にそのまま渡り、
  前回のセッションに戻れる
- ターミナル: **`akari status`** — 起動せずに状態だけ確認（`--json` で機械可読、`--full` で整合性検査も）。
  エージェントが進めた作業があれば、「やったこと 3 件（最新: 無音を 12 か所カット）」「確認待ち 1 件」の
  ように件数が続けて出る
- アプリ: ホームの「最近のプロジェクト」から開く。プロジェクトのホームは「続きから開けます。」と
  今の段階を出し、「やったこと」から、見ていないあいだの作業の一覧（変更を見る / ここまで戻す）を開ける

## 入口をまたぐ

状態はすべてファイル契約にあるので、こういう移動が自由にできます:

- ターミナルで作ったプロジェクトを、後日アプリで開いてレビューだけする
- アプリで付けた注釈（review.json）を、セッション内で「注釈に対応して」と消化する
- 別マシンに git clone して続きをやる（セーブデータはテキストなので git で完結）
