# キャンバス v0

キャンバスは `edit.json` v2 の `source.kind: "group"` に付ける明示的な編集の器。画面では `canvas` の無い既存 group も「キャンバス」と呼ぶが、保存データは一律に変換しない。

```json
{
  "id": "canvas-1", "name": "導入", "at": 300, "duration": 150,
  "source": { "kind": "group", "canvas": {
    "origin": "user", "durationMode": "fixed", "intent": "最初に見せる内容",
    "background": { "type": "color", "color": "#112244" }
  } }, "items": []
}
```

- `origin` は `user` または `plan`。v0 の `durationMode` は `fixed`。`content` は将来用に予約する。
- `background` は `none` または `color`。色は `#RRGGBB`。背景はキャンバス区間内で全面に表示し、子より下へ置く。音声は変えない。
- 空のキャンバスは区間を持つ仮枠。意図は空のときだけプレビューの点線枠に表示し、出力には焼き込まない。
- 子の `at` は親に対する相対時刻。親を動かすと子の絶対時刻も動く。出し入れでは各子の絶対時刻、見た目、重なり順を保つ。
- `fixed` の尺変更は表示範囲だけを変える。子の時刻・尺を変えず、親の区間外は描かない。このため `v2.child-in-parent` は警告とする。
- タイムラインの範囲端は整数フレームへ丸める。整数秒から 1 フレーム以内の端はその整数秒へ吸い付け、マウスのピクセル誤差で 0:10〜0:15 が 301/149 フレームにならないようにする。
- 段をまたいで開始時刻が同じ item が 3 個以上なら、最上段の対象 item の位置に 1 行へ畳む（表示のみ）。同時刻の非 media が 3 個以上あるときは、それらだけを対象にして全尺の本編 media を巻き込まない。展開すると元の行とチップへ戻る。保存データを変えるのは明示的な「キャンバスにする」操作だけ。空になっても自動でほどかない。
- 置いた字幕を子へ入れるときは `caption` item を作り、元の `captions` 袋の `source.exclude` に同じ字幕 id を入れて二重表示を防ぐ。移動後に外へ出すときは絶対時刻を保つ独立した `caption` item とし、`exclude` を維持する。
