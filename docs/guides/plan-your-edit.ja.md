# 編集計画を立てて実行する

分析結果をもとに、エージェントが編集方針を提案し、選んだ進め方に従って `edit.json`
（編集のセーブデータ）へ落とし込む中心工程です。スキルは `edit-plan`。

## いつ使う

- 素材の分析（[analyze-footage / analyze-project](./analyze-footage.ja.md)）が済んでいるとき
- カット構成・BGM・SFX・B ロール・テロップ計画をまとめて決めたいとき
- 素材ゼロから生成で組む場合（→ 先に [ゼロから企画する](./plan-from-scratch.ja.md) を参照）。
  素材が無いときは、質問の対話から `plan.json` の仮のタイムラインを作ることから始めます

## 頼み方

「編集方針を立てて」「この分析レポートをもとに 60 秒に縮めて」「テンポ重視でカットして」

自分で先にタイムラインを配置・トリムしたい場合は、`edit.json` を保存して「今こんな感じどう？」
「このカット見て」と頼めます。[critique-cut](../../skills/critique-cut/SKILL.md) がタイムラインで
使われている素材区間と合成後のコンタクトシート 1 枚だけを観察し、編集を書き換えずに所見を
返します。構成全体に及ぶ直しは edit-plan へ戻し、点の直しは注釈を付けて
[QA・レビューして直す](./review-and-fix.ja.md) へ進めます。

## 進め方の 3 モード（判子は書き出しの 1 回）

| 表示語 | ID | 何が起きる | 判子 |
|---|---|---|---|
| そのまま | `full-auto` | 言った通りに入れて見ずに書き出す。出た後に capture 1〜2 枚 + lint 結果を添える | 0 回 |
| 提案つき（既定） | `checkpoint` | 頼まれた物に加えて良さそうな物もタイムラインに入れて見せる。人間がプレビューで見て、要らなければ消す・直す・出す | 書き出しの 1 回だけ |
| 一緒に作る | `collaborative` | 方針 → 素材計画 → 実行の 3 段階で確認する | 段階ごと |

既定は**提案つき**。edit-plan は頼まれた物に加えて良さそうな物もタイムラインに入れて見せます。
途中では止まりません。プレビューで見て、要らなければ消す。書き出しボタンが唯一の判子です。

**そのまま**は見ずに書き出し、出た後に capture 1〜2 枚と lint 結果を `.akari/reports/` に添えます。
頼まれていない物（B ロール・BGM・演出）は足しません。

**一緒に作る**だけは 3 段階で止まります。方針（サムネ案・カットの強さ・字幕の方針・章立て）→
素材計画 → 実行の順に、チャットで推奨と代案を見せ、明示の承認が来るまで次へ進みません。
分析レポート（analyze-project）が判断の一次証拠です。

切り替えは進め方フォーム（ホームの「今回の進め方」。`.akari/intake.json` の `autonomy`）で行います。
一言の指示は進め方フォームより優先されます。

課金と外部送信の承認はモードと独立です（[接続と API キー](../how-to/connections.ja.md)）。

決定はすべて `decision-log.md` に追記されます。「なぜこうなったか」は後から必ず追えます。
提案をプレビューに入れた時点で機械が予測 1 行を書くため、承認を挟まなくても記録は途切れません。
書き出すときに、消した物・直した物・そのままの物が結果の行として足されます。

## 止まる場所 — 自動化の門

どの進め方でも、**戻せないこと・外に出ること・お金や権利に触ること**の前では止まって、人の返事を待ちます。
プロジェクトの中で閉じていて戻せる変更（`edit.json`・`captions.json`・`planning/`・生成した素材の追加）は、
見ていないあいだも止めずに進みます。

| 門 | 止まるとき |
|---|---|
| 公開・投稿 | YouTube 等への公開、共有リンクの発行 |
| Lab への提出 | Lab やストアへの提出 |
| 有償 | 有償の生成・購入（見積つき） |
| 外部への送信 | 素材や文書を外部のサービスへ送る |
| 元素材の削除 | 取り込んだ元素材の削除・上書き |
| ライセンスの確認 | 出どころ不明・商用不可の疑いなど |
| 作り方の確認点 | 作り方（Playbook）が宣言した確認点 |
| 確認の依頼 | 人が「確認して」と頼んだ所 |

止まると画面に門の帯が出て、「承認」か「やめる」を選べます。エージェントは自分で承認できません。
書き出しは元素材を上書きしない限り戻せるので、門ではありません。

### やったこと

止まらずに進んだ作業は「やったこと」に残ります。時刻・誰が（あなた / 相棒 / 外のエージェント / 無人）・
1 行の要約・変わったファイル数が新しい順に並びます。プロジェクトのホームか、門の帯から開けます。

- **変更を見る** — その節目の差分を見る
- **ここまで戻す** — その節目の前の状態にファイルを戻す。戻したこと自体も節目として残るので、さらに戻せる

戻るのは編集データと文書だけです。取り込んだ元素材と書き出した動画は履歴に入りません。
プロジェクトが git を持たないときは、一覧は出ません。

## 生成されるもの

| ファイル | 内容 |
|---|---|
| `edit.json` | 編集の SSOT。素材・段の並び・クリップ・音声・字幕・サムネイル |
| オーバーレイ HTML 断片 | テロップ・図形など（`tracks[].items[]` の HTML クリップから参照） |
| `captions.json` | 字幕データ |
| `planning/script.json` | 台本の予定とメモの行（あれば） |
| `decision-log.md` | 判断の記録 |

## edit.json のここだけ知っておく

編集状態の正本はこのファイルです。スキーマの正確な定義は
[Reference](../README.ja.md#reference) の各契約にありますが、日常の操作で意識するのは:

- **新規プロジェクトは edit v2** — `sources[]` に素材、`tracks[].items[]` に映像・音声の
  クリップを置きます。クリップは `source.kind` と `source.src` で内容と素材を指します。
- **木になっている** — アイテムは子の `items[]` を持てます。`source.kind: "group"` のまとまり（画面ではキャンバス）の
  中に、さらにクリップを入れられます。子の `at` は親からの相対フレームで、`items[]` の順が前後の重なりです。
- **段は順序だけを持つ** — `lane` で映像と音を分けますが、「本編」「レイヤー」という種別は
  ありません。映像の重なりは `tracks[]` の後ろほど前面、という段の並び順で決まります。
- **出力時刻は整数フレーム** — `at` / `duration` はフレーム、素材のトリム位置
  `source.in` / `source.out` は原本秒です。
- **空の段も残る** — `items[]` が空でも宣言済みの段は表示されます。最後のクリップを移動しても
  自動削除されず、明示的な「トラックを削除」操作だけが段を消します。

手で直接編集しても構いません（git diff で差分が追えます）。ただし変更後は
[edit-lint](./review-and-fix.ja.md) をかけるのが約束です。全文を読まず、id で grep して該当行だけを
読む方法は [edit.json の読み方](./edit-json-access.ja.md) を参照してください。

## 台本の予定とメモ

台本パネルは字幕に加えて、**予定**（ここに何を入れるつもりか）と**メモ**（気づき・指示）の行を持てます。
3 種類は時刻順に 1 本の列で並びます。予定は区間を持てて、済んだらチェックで切り替えます。
「＋ メモ」で今の再生位置にメモを足します。

予定とメモは `planning/script.json` に入ります（字幕の正本は今までどおり `captions.json`）。
タイムラインの最上段に「台本」の段が出て、予定は帯、メモは点で見えます。ここでは編集せず、
直すのは台本パネルです。作り方から始めたプロジェクトでは、作り方の内訳が予定の行になります。

字幕の見た目（字幕スタイル）は、字幕全体にも、選んだ文字だけにも当てられます。

## トランジション

クリップの境目には、トランジションを付けられます。

- **見本で選ぶ** — 境目を選ぶと、見本つきの一覧から種類（クロスフェード・ワイプ・スライド・ズームなど）を選べる。
  選ぶと 0.5 秒で付き、インスペクターで種類・向き・長さ（0.1〜3 秒）・位置を直せる。
  ライブラリのスタイルから境目へ落としても付く
- **寄せる** — 位置は「中央」「前に寄せる」「後ろに寄せる」。付けるときは素材の余りがある側へ自動で寄り、
  インスペクターで直せる（「おすすめに戻す」で元に戻る）
- **止め絵で埋める** — 素材の余りが足りないとき、足りない分だけコマを止めて埋めるかを聞かれる。
  タイムラインの長さは変わらない。埋めた区間は帯で見える

余りが足りないままだと、トランジションは短くなります。クリップの間にすき間があるときや、
映像トラックが複数あるときは付けられません（理由が画面に出ます）。

## 話者を分けた字幕

会話やインタビューの素材は、文字起こしの段階で話者を分けられます（人数だけ指定）。
声のサンプルがあるチャンネルの人物となら、名前の候補も出ます。決めるのは人です。
詳しくは[素材を分析する](./analyze-footage.ja.md)を参照してください。
