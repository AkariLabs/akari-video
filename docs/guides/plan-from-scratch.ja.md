# ゼロから企画する

素材がまだ無くても、企画・調査・構成づくりから始められます。スキルは `research-plan`。
撮影前の一周（ネタ出し → 調査 → 企画書 → 絵コンテ → 撮影リスト）を担当します。

## いつ使う

- 「何か作りたいがネタから決めたい」
- 撮影の前に構成と撮影リストを固めたい
- 生成素材中心で 1 本組みたい（撮影なし）

## 始め方

入口は 2 つあります。

- **白紙から** — 「動画の企画から始めたい」「◯◯のテーマでネタ出しして」と頼む。ネタ出しから一周する
- **作り方から** — 手元やチャンネルに作り方（Playbook）があるなら、そこから始める。ホームの「<!-- F ui.home.startButton -->＋ 新しい動画を始める<!-- /F -->」で
  「作り方から」を選ぶか、CLI で `akari new <dir> --from <作り方の id>`。流れと設定を引き継ぎ、
  空き枠つきのタイムラインと台本の予定の行ができる。`akari playbook list` で選べる作り方を確かめられる

作り方は工程と確認点を書いた文書です。ネタ出しから決め直したいときは白紙から始めます。

## チャンネルとの関係

プロジェクトをチャンネルの中に作ると、そのチャンネルの持ち物を企画に使えます。

- **型** — 企画書の下書き。チャンネルの型を選ぶと、`planning/` に入ります
- **人物** — 出演者や登場人物の記録（名前・読み・写真・声）
- **記憶** — 人物と単語帳（`.akari/memory/word-book.json`）。台本パネルで直した語も単語帳に足される
- **<!-- F ui.library.channelSettings -->チャンネルの設定<!-- /F -->** — ロゴ・フォント・色などの決まり

`.akari/connections.json` に記憶の接続が宣言されていれば、`research-plan` は企画の最初にその入口
（既定は `INDEX.md`）を読みます。読んだファイルは `research-plan.json` の `sources[]` に残ります。
宣言が無くてもエラーにはなりません。

## 流れ

1. **ネタ出し（ideate）** — テーマ候補を複数提示
2. **調査** — ターゲット・競合・トレンドを調べて根拠を付ける。無料の情報源だけで最後まで進められる
3. **ネタ選定（topic-select）** — 決定カードで承認
4. **構成・絵コンテ（storyboard）** — 構成案を提示し、structure-confirm の決定カードで承認
5. **撮影リスト（shotlist）** — 何をどう撮るかのリスト

承認の場所は 2 つだけです（ネタ選定・構成確認）。候補と根拠が並び、選ぶと決定が記録されます。
選ばずに「すべておまかせで確認」を押すこともできます。承認の前に次の工程へは進みません。
有償の調査 API は、費用を示して承認されてから呼びます。チャットで返事をしただけでは課金されません。

構成確認の直しは、チャットか、レポートの「注釈をコピー」で貼り戻して伝えます（`planning/plan-comments.json`）。

## 生成されるもの

| ファイル | 内容 |
|---|---|
| `planning/research-plan.json` | 企画の SSOT（topic / target / structure / shot_list） |
| `planning/research-plan-report.html` | 企画レポート（読み取り専用）。ネタ候補・競合・構成・絵コンテ・撮影チェックリストの 5 面 |
| `planning/research-plan-report.html.decisions.json` | 決定カードの確定の記録 |

## 撮影しない場合 — 仮枠クリップ

素材ゼロで組む場合も、正本は最初から `edit.json` のタイムラインです。仮枠は
**タイムライン上の静止画クリップ + 素材の隣の `<path>.meta.json`**。静止画クリップが尺と場所を
持つので、そのまま完成品にしても、後から同じクリップを動画へ差し替えても構いません。

`akari generate still <projectDir> --spec <beats.json>` で静止画仮枠を作ります。絵をまだ決めずに
尺と並びだけ確認するなら `--placeholder` で無料の文字カードを使います。動かすクリップだけを選び、
`akari generate video <projectDir> --item <itemId>` へ進みます。有償生成は見積と費用承認の後に
`--yes` を付けて実行します。

台本の「予定」の行（何秒に何を入れるか）はタイムラインの最上段にも出ます。
詳しくは[編集計画を立てて実行する](./plan-your-edit.ja.md)を参照してください。
