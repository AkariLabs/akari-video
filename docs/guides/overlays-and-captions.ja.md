# テロップ・字幕・図表・3D を作る

映像に載せる表現は、AI が HTML/CSS/Three.js で描く「<!-- F ui.library.motionParts -->動く部品<!-- /F -->」（HTML の素材）と、
データで持つ字幕・文字・図形でできています。見た目は言葉で頼んでも、ライブラリの
スタイルを当てても、ツマミで直しても作れます。
スキルは `overlay-authoring`（edit-plan の実行段階から呼ばれるほか、単独でも使えます）。

## いつ使う

- 「ここにテロップを入れて」「この数字を表で見せて」「タイトルを 3D で回して」
- 字幕のスタイルを変えたいとき、字幕の一部の語だけ目立たせたいとき
- 図形・吹き出し・矢印を足したいとき
- サムネイルを作りたいとき

## 作れるもの

| 種類 | 例 |
|---|---|
| テロップ | 見出し・チャプターカード・強調ワード |
| 字幕 | 発話字幕（カラオケ表示・強調対応）。見た目は「字幕全体」にも「選んだ文字だけ」にも当てられる |
| 文字のスタイル | 多層の縁・グラデーションや柄の塗り・ずらし影（→ [文字のスタイル](#文字のスタイル)） |
| テロップ台 | 文字の後ろに敷く飾りの板（→ [テロップ台](#テロップ台)） |
| 表・グラフ | 数値の可視化 |
| 図形 | 基本の図形・線・矢印・吹き出し（→ [図形](#図形)） |
| 3D | Three.js によるタイトル・オブジェクト演出（→ [3D](#3d)） |
| モーショングラフィックス | 登場・強調・退場・キーフレームの動き |
| サムネイル | 静止画サムネ |
| text-behind-person | 人物の背後に文字を回す演出（人物マット抽出と連携） |
| 背景 | 区間ごとに差し替えるフレーム全面の背景ボード（→ [背景](#背景role-background)） |

字幕の `style` は 5 値（`plain` は動きなしの通常表示）:

| スタイル | 挙動 |
|---|---|
| `plain` | 動きなしで表示 |
| `karaoke` | 発話に合わせて単語をハイライト |
| `pop` | 発話に合わせて単語をポップ表示 |
| `reveal` | 1 行ずつ順に表示 |
| `reveal-word` | 単語を発話まで隠し、発話後は表示したままにする |

## 仕組み — 触れる動く部品

生成されるのは HTML 断片で、`tracks[].items[]` の HTML クリップから参照されます。
規約が 3 つあります:

1. **タイミングは `edit.json`** — クリップの開始と長さはタイムラインの item が持つ。
   断片ルートに `data-start` / `data-duration` を置かない。素材本来の長さが必要なら
   `data-akari-natural-duration` に秒数を記録する。ドラッグは `edit.json` を更新し、
   断片内のアニメーションはクリップ先頭を 0 とするローカル秒で書く
2. **調整可能な値は CSS 変数** — 色・サイズ・位置などツマミにしたい値は CSS 変数で宣言。
   ビューワーが変数を発見してスライダー / カラーピッカーを自動生成する。`--x` / `--y` /
   `--scale` / `--rotate` は `role: "background"` に限らず全部の動く部品でランタイム予約
   （ランタイムがコンテナへ必ずインライン設定する）であり、自前ツマミとして参照・再定義する
   とフォールバックが無音で効かなくなる。別名を使う（`edit-lint` が
   `overlays.reserved-css-var-reference` で警告する）
3. **クラス名と `@keyframes` 名はページ全体で共有される** — 断片ごとに固有の接頭辞を付ける
   （例: `.lower-third-…` / `@keyframes lower-third-…`）。他の断片から名前を写さない。クリップの
   時間が重なるとき、後から読み込んだ断片の規則が別クリップの要素に効くため、`edit-lint` が
   `overlays.fragment-css-collision` で警告する。同じ断片ファイルを複数クリップで使うのは衝突ではない

つまり「AI が自由に描いたもの」でも、人間は HTML を読まずに GUI で微調整できます。
テキストはダブルクリックで直接編集でき、変更はデータに書き戻されます。

プレビューで動く部品の中をクリックすると、押した場所の要素が選ばれます（Enter で中の要素へ、
Esc で部品全体に戻る）。選べるのは id か class の付いた要素で、ドラッグか矢印キーで動かせます。
動かした分は元の HTML を書き換えず、プロジェクトにだけ残ります。

## 背景（`role: "background"`）

HTML クリップの変数に `"role": "background"` を宣言すると背景ボードになります。必ずフレーム
全体を埋め、動かせず、区間ごとに差し替える使い方を想定した種別です。位置・拡大の
ツマミ（`--x` / `--y` / `--scale` / `--rotate`）はロックされ（ランタイムが出力フレームへ
固定）、`transform` も持てません。字幕や図表の後ろに敷く単色・グラデーション・パターン
背景に使います。`role` なしの通常の動く部品の挙動は従来どおりです。スキーマで表現
できない部分（`vars` によるロック済みツマミの上書き・背景区間の重なり）は `edit-lint` が
検査します。

## 字幕を作る（akari captions）

文字起こし済みのプロジェクトで実行します。

```sh
akari captions <project-dir>
```

- 敷き詰め禁止: 語の時刻を使い、無音の隙間を字幕で埋めません。
- 読み切り猶予: 末尾語の end に既定 0.3 秒を加え、次の字幕に重なる分だけ縮めます。
- 短時間床: 次の字幕を超えない範囲で既定 1.0 秒まで延ばし、届かない場合は warning を返します。
- 文節で切る: 句点 > ポーズ > 読点 > 文字数 / 秒数の優先順で分割します（既定 20 字・7 秒、`--split none` で旧挙動）。
- 素材尺で丸める: probe の素材尺があれば end を丸め、残りが 0.2 秒未満の字幕は warning とともに落とします。
- 単語帳を当てる: 解決できる単語帳を既定で適用します（`--word-book <path>` で追加、`--no-word-book` で抑止）。

手直しは台本パネルか `captions.json` を直接編集します。

文字起こし時は、検出した無音へはみ出した語を既定で実際の発話区間へ吸着します。既存の
`captions.json` は `akari captions <project-dir> --retime`、または台本ヘッダの
「⏱ 発話に合わせ直す」で同じ補正を後から適用できます。本文は変えず、手直し済み
（`edited: true`）の行では行の `start` / `end` を保護します。
隣り合う行の表示窓が重なるときは境界を分け合い、手直し済みの行は動かしません。
手直し済みの行では、すべての語を行の枠内に収めます。
自動の発話吸着を止めるには `akari media transcribe` に `--no-snap` を渡します。
行末の無音チップ・範囲エディタ（無音の灰帯・波形・語の帯）・「カットを整える」の無音候補・行の出力時刻は、すべてその行が属する素材（`src`）で解決するため、素材が複数あるプロジェクトでも取り違えず、素材の境目は語の隙間として扱います。
`speaker` はクラウドの話者分離（ElevenLabs Scribe 等）で埋まります。ローカルエンジン（SpeechAnalyzer / whisper.cpp）では `null` のままです。

## 行数・折り方・拡大回転

object 形式の `captions.json` では `display_policy.lines` に 1〜6 を指定できます（既定 1）。
`display_policy.wrap` は各行の作り方を指定します。既定の `multi` は連続する最大 N 断片を
同時表示し、`fold` は 1 断片を `max_line_units` の行予算で最大 N 行へ折ります。
台本パネルで手置きした改行（／）は、`display_policy` が無いプロジェクトでもプレビューと書き出しに反映されます。
タイムラインの字幕帯もプレビューと同じ表示断片ごとに分かれ、字幕トラックのヘッダで区切りの表示を切り替えられます。

`text_style.scale` は字幕プレートの等比拡大率（0.4〜3、既定 1）、`text_style.rotate` は
回転角（-180〜180 度、既定 0）です。どちらも字幕の位置を中心に変形します。`scale` と
`rotate` は共有字幕カーネル 1 か所で解決されるため、プレビューと書き出しは同じ宣言値を
読みます。

## 字幕の見た目 — 全体にも、選んだ文字だけにも

字幕の見た目は「<!-- F ui.library.captionStyle -->字幕スタイル<!-- /F -->」として当てます。ライブラリの<!-- F ui.library.captionStyle -->字幕スタイル<!-- /F -->・<!-- F ui.library.myStyles -->自分のスタイル<!-- /F -->・
インスペクターのどこから当てても同じ結果になり、当てても字幕の大きさは変わりません。
字幕の大きさを変えると、縁・影・グロー・台紙の余白も同じ比率で変わります。

- **字幕全体**: 行を選んでスタイルを当てる。台本パネルでは行の「<!-- F ui.library.captionStyle -->字幕スタイル<!-- /F -->」から選ぶ
- **選んだ文字だけ**: 台本パネルで語を選び「✦ 選んだ文字だけ」から当てる。出力プレビューには
  選んだ文字が点線の枠で示される。戻すときは「字幕全体の見た目に戻す」
- 同じ操作は短い表示で「✦ 強調」とも出る。以前の「強調語」
  （`emphasis_words`）は、見た目を固定するときに選んだ文字へ移る
- 選んだ文字に当てられるのは、色・太さ・斜体・下線・字間・拡大・上下のずらし・回転・縁・影・
  グロー・台紙。フォントと大きさは字幕全体にだけ当てられる（範囲に当てられない項目は外して知らせる）
- 台紙・影・グローは、プレビューと書き出しで同じに描かれる。語ごとの表示や文字送りと、
  選んだ文字の台紙・影・グローを同時に使う字幕は、速い GPU 書き出しではなく通常の書き出しに
  自動で切り替わる（理由は書き出しの画面に出る）

保存先は `captions.json` です。字幕全体の見た目は `text_style`、選んだ文字は `runs[]`
（文字の範囲ごとの `look` と `motion`）に値として入ります。契約は
[字幕の見た目 v1](../contract-2026-10-12-caption-look-v1.md)・
[選んだ文字の範囲 v0](../contract-2026-09-24-caption-runs-v0.md)・
[強調語 v0](../contract-2026-08-23-captions-emphasis-words-v0.md) です。

### 前の形の字幕を固定する

前の形のまま残っている字幕があるプロジェクトを開くと、「見た目を固定」をおすすめします（1 回だけ。
確認するまで書き換えません。履歴に 1 件として残り、1 回の取り消しで戻せます）。
コマンドからは次のように差分の確認と保存ができます。

```sh
akari captions migrate-look <project-dir> --dry-run   # 差分だけ確認
akari captions migrate-look <project-dir>             # 固定して保存
```

## 文字のスタイル

字幕と文字の見た目は、重ねて作り込めます。

- **縁**: 複数の層を重ねられる（外から内、背面から前面の順）。層ごとに色・太さ・ずらし（右・下）を決められ、
  ずらした縁で「ずらし影」を作れる
- **塗り**: 単色・グラデーション（2 点以上の色と角度）・柄。柄は `diamond` / `dot` / `stripe` /
  `gingham` / `skull` / `hazard` / `night` / `heart` / `thunder`
- そのほか、影・グロー・台紙（座布団）・字間・大文字化
- 色や太さはすべてツマミ。派生スタイルは、ベースのスタイルをツマミで変えて作る

作ったスタイルは「<!-- F ui.library.myStyles -->自分のスタイル<!-- /F -->」に保存して、別のプロジェクトでも使えます。
契約は [textstyle v1](../contract-2026-10-02-textstyle-v1-rich.md) です。

## テロップ台

テロップ台は、文字の後ろに敷く飾りの板（枠・バッジなど）です。Lab にある動く部品で、
置くと文字と色のツマミが付きます。文字は台の上でダブルクリックして打ち直せ、
同じ台を別の文字で何本も使えます。

自分で作るときは、AI に「こんなテロップ台がほしい」と頼みます。板は SVG で描き、文字は
`data-akari-slot` を付けた要素に入れます（打ち直しは `edit.json` の `source.params` に保存され、
元の HTML は書き換わりません）。

## 動き・キーフレーム

- **登場・強調・退場**: インスペクターの「動き」でプリセットを選び、尺・イージング・量を変える。
  周期のあるループも付けられる
- **キーフレーム**: 位置・拡大・回転・不透明度を時刻ごとに打つ。プレビューで動かしたあと、
  選択の上の「◆ キーを打つ」でその時刻にキーを打てる。菱形をクリックするとその時刻へ移る
- **動きを描く**: プレビューでドラッグした道筋が、要素の位置のキーフレームになる

契約は [動きとキーフレーム](../contract-2026-08-30-motion-and-keyframes-v0.md)・
[動きの重ね方](../contract-2026-09-25-motion-layers-v0.md) です。

## 図形

ライブラリの「図形」の棚から、基本の図形・多角形・矢印・ライン・漫画の吹き出し・雲・ハート・
雫・歯車・フローチャート・横断幕などを置けます。置いた図形は、棚の形と既定値を値としてコピーしたもので、
あとで棚が変わっても影響されません。

- 塗りと枠は単色か、グラデーション（2〜5 色）。透明度は色ごとに持つ
- ラインは実線・破線・点線と、両端のパーツ（三角・矢じり・丸など）を選べる
- 吹き出しは形（楕円・角丸・ギザギザ・雲など）としっぽの向き・長さを選べる

契約は [図形 v1](../contract-2026-09-25-shape-item-v1.md) です。

## 3D

3D は Three.js + glTF で作ります。AI が書く断片は、実行しない JSON の宣言（モデル・カメラ・ライト・
環境）を持ちます。

- 3D の部品を選ぶと、インスペクターに「3D」の節が出ます。回転を数値で変えられ、キーフレームで動かせます
- プレビューでは本体を押して移動し、色の付いたリングをつかむと回せます
- ライブラリの 3D モックアップをクリックかドラッグで置けます。素材の動画や画像を 3D の上に
  落とすと、その画面に映ります（画面の素材が大きすぎると書き出しに失敗する場合があり、警告が出ます）
- 「色のセット」を宣言した 3D は、ツマミ 1 つで材質の色を切り替えられます
- キーフレームで動く 3D も、GPU の速い書き出しで描けます

Three.js で表せない映像（被写界深度・レイトレースなど）や、使い回すクリップは
[3D シーンをベイクする](./bake-3d.ja.md)で映像に焼きます。

## サムネイル

サムネイルは、HTML のシートを画像に焼いて作ります。経路は 3 つです。

- **実フレーム + HTML の文字組**: 動画のコマを使い、文字・数字・ロゴ・UI は HTML で組む
- **画像生成**: 背景やモチーフを生成する
- **混成**: 生成した背景に、HTML で最終の文字を載せる

日本語の文字・ロゴ・数字は、画像生成に描かせず HTML で組みます（誤字や崩れを防ぐため）。
サムネイルのシートは動画の動く部品ではないので、タイミングの指定はいりません。

## フォントの取り込み

フォントファイルはライブラリにドロップします（動画や音と一緒に落としても、全部が取り込みに並びます）。

- 取り込むとプレビューがすぐ読み直され、「テキスト › フォント」にそのカードが開く。アプリの開き直しは不要
- ファイル名ではなく書体の名前で並び、カタログの同じ書体とは 1 枚にまとまる。インスペクターのフォント一覧には「自分で入れた」と出る
- カードから「場所を見る」「ライブラリから消す」ができる
- 手元に無い書体には「使える」「ダウンロード」「入手が必要」の印が付く。無料で取得できる書体は、押すとすぐダウンロードが始まる。
  入手できない書体は、入手先の案内と「代わりの書体で当てる」を出す
- 動く部品の断片に使う文字が、参照しているどのフォントにも無いとき、`edit-lint` が
  `overlays.fragment-font-glyphs` で知らせる。断片のスクリプトが文字を作るときは、
  断片のルートに `data-akari-font-chars` で使う文字を宣言する

## 作品の言語と、素材の英語化

作品ごとに言語を持てます。英語の作品では、字幕の組み方（1 行の字数・改行・読む速さ）、
言い淀みの検出、読み上げの声が英語向けになり、字幕の既定の書体は Noto Sans になります。

素材（動く部品・スタイルなど）の `meta.json` には、任意の `i18n.en` で英語の
`title` / `description` / `when_to_use` / `knobs` / `groups` / `aliases` を持たせられます。
日本語の欄が基底で、英語の画面では UI の言語 → en → 基底の順に欄ごとに選ばれます。
同梱の素材とスタイル名には英語の名前と説明が付いています。

## 頼み方の例

- 「冒頭に番組タイトル風のテロップ。白抜き・下からスライドイン」
- 「この区間の字幕を強調スタイルにして、キーワードだけ色を変えて」
- 「売上の推移を棒グラフの動く部品にして 12 秒から 5 秒間」
- 「人物の後ろに大きく『開幕』って出したい」（text-behind-person）
- 「ここに矢印と吹き出しを足して」
- 「このスマホのモックアップに、撮った画面を映して回して」

見た目の大改造も自然言語で頼めば AI が HTML を書き換えます。
ちょっとした調整はツマミ（CSS 変数）で、大改造は言葉で、が使い分けです。
