# ナレーションを付ける

原稿から音声を生成して `edit.json` に組み込みます。スキルは `generate-narration`。
自分の声は、プレビューを再生しながらマイクで録る「アフレコ」でも入れられます。

## いつ使う

- 解説動画・VLOG にナレーションを付けたいとき
- 仮ナレ（尺確認用）を素早く当てたいとき
- 自分の声のクローンでナレーションを作りたいとき
- 映像を見ながら、自分の声をそのまま録りたいとき（→ [アフレコ](#アフレコ)）

## エンジン

| エンジン | 特徴 | 費用 |
|---|---|---|
| VOICEVOX | ローカル実行・キャラクター声。キー不要 | 無償 |
| Gemini TTS | 既製の声 30 種。fal 経由（`gemini-tts`・`gemini-3.1-flash-tts`）と Google AI の直接呼び出し（`gemini-3.8-flash-tts`） | 有償 |
| Fish Audio | 日本語の公開の声。自分の声の参照も使える | 有償 |
| fal Qwen3-TTS | 自分の声のクローン | 有償 |

ほかに、fal 経由の ElevenLabs v3・MiniMax Speech 2.6 HD・Chatterbox 多言語・Index TTS 2 と、
別に立てたサーバーにつなぐ彩（Irodori-TTS、お試し）があります。使えるエンジンと接続の状態は
`akari narration engines --json` で見られます。

有償エンジンは、見積もりを出して明示的に承認してから実行されます（承認なしでは何も送らず止まります）。
鍵（`FAL_KEY`・`GEMINI_API_KEY`・`FISH_AUDIO_API_KEY`）は `manage-connections` で扱い、
接続できていないエンジンは選べません。勝手に課金されることはありません。

## 頼み方

- 「この原稿でナレーションを付けて」
- 「まず仮ナレで尺を確認したい」（→ VOICEVOX で即生成）
- 「自分の声で作りたい」（→ 声プロファイルの作成から案内）
- 「仮ナレを Fish Audio の声に差し替えて」（同じ原稿・同じ位置で、新しい id で作り直す）

アプリのインスペクターの「ナレーションを置く」からも作れます。クラウドの声は、試聴の前に
費用の承認が 1 回入ります。

## 生成されるもの

- 音声ファイル（プロジェクトの `out/narration/` に配置）
- `edit.json` の `audio.narration[]` への登録（どの区間にどの音声か）。表示原稿（`script`）、
  読み上げに使った読み原稿（`reading`）、出どころ（`provenance`。VOICEVOX の声にはキャラクターのクレジットも）を持ちます

生成後は [edit-lint](./review-and-fix.ja.md) が尺・重なり・参照切れを検査します。
作品の言語（日本語 / 英語など）に合わせて、読み原稿の作り方と声の選び方が変わります。

読み方や話し方の指示（「明るく読んでください：」など）を本文に混ぜないでください。
そのまま読み上げられることがあります。抑揚は句読点と語順で作り、話し方は対応エンジンの
スタイル指定で渡します。

## 声を聞き取りで確かめる

```sh
akari narration verify --project <プロジェクト> --id n-0001 --json
```

生成した音声をこのパソコンの文字起こし（SpeechAnalyzer か whisper.cpp）で聞き取り、字幕の文字と
照合します。クラウドには何も送りません。「ok」「check」「ng」の目安で、読み間違いや指示文の読み上げを見つけます。

## 声プロファイル（自分の声）

自分の声を使えるのは、本人の声だけです。他人の声や、動画から切り出した声は使えません。

1. 決まった台本を読んで録音する（約 20 秒の `quick-v1`、約 60 秒の `extended-v1`）
2. このパソコンで台本との一致・長さ・音量を確かめる（クラウドに送る前の必須の確認。一致 70% 以上）
3. 本人の同意を記録して声プロファイルを作る。クラウドで声を作るときは、録音を送ることへの同意が別に要る

声プロファイルはプロジェクトの外（`~/.akari/avatars/<人>/voice/` 配下）に保存され、
プロジェクトをまたいで再利用できます。

```sh
akari voice scripts --json
akari voice check --audio <録音> --script quick-v1 --json
akari voice create --avatar <人> --id <声のid> --label <表示名> --audio <録音> --script quick-v1 --consent-self --json
akari voice profiles --json
```

## アフレコ

タイムラインの右上（虫眼鏡の左）の 🎙 から、声を録ってそのままタイムラインに置けます。

- **再生しながら録る**: 赤丸を押すと、再生ヘッドの位置からプレビューを再生しながら録音します。止めると、録った声が録り始めた位置に置かれます
- **録音中はプロジェクトの音を消す**: 録っている間だけ、動画の音や BGM を止められます。イヤホンで聞きながら録るときは切ります
- **台本の行から録る**: 台本の行の 🎙（行を選んだときのバーの「🎙 アフレコ」）で、その行の頭から、読む文を見ながら録れます。録った行には「🎙 録音済み」の印が付きます。置いた声は、その行の文を `script` として持ちます
- **ノイズを取り除く**: 置いた声にノイズを減らす処理を掛けられます。声はそのままで、無音のところのノイズが下がります。音声クリップの「ノイズ除去」と同じ方式（NLM は声を保つのでおすすめ、FFT は軽くて速い）で、元の音声は書き換えません
- 入力するマイクと音量を選べて、レベルメーターで録れているかを確かめられます

## BGM との関係

BGM の `ducking` を有効にすると、ナレーションや声の区間で BGM が下がります。
プレビューと書き出しで同じ決まりで下がります。
