# 国土地理院タイルから地形の素材を作る

`akari geo terrain` は、国土地理院の標高タイル（`dem_png`）と写真タイル（`seamlessphoto`）を
取得して bbox の範囲に結合・切り出し、3D の地形宣言が読む 3 つのファイルを出力します。

地理院タイルは無料・認証不要ですが、**出典の表示**が条件です。コマンドは `terrain.json` と
CLI の出力に必ず出典を書きます。

## コマンド

```sh
akari geo terrain \
  --bbox 139.3445,35.5960,139.3555,35.6050 \
  --zoom 14 \
  --out assets/terrain/sagamihara
```

| オプション | 意味 |
|---|---|
| `--bbox <西,南,東,北>` | 世界測地系の度で範囲を指定（必須）。`西 < 東` かつ `南 < 北` |
| `--out <dir>` | 出力先（必須） |
| `--zoom <1-14>` | タイルのズーム（既定 `14`）。大きいほど精細でタイル数が増える |
| `--max-tiles <n>` | 1 層あたりのタイル数の上限（既定 `64`） |
| `--cache-dir <dir>` | タイルのキャッシュ先（既定 `~/.akari/cache/geo`） |
| `--json` | 結果を JSON で出力 |

bbox に必要なタイル数が上限を超えるときは、**取得を始める前に**止まり、収まる zoom を案内します。
勝手に zoom を下げることはありません。

## 出力

| ファイル | 内容 |
|---|---|
| `heightmap.png` | 標高タイルを `gsi-dem` の符号化のまま結合（8bit RGB: `R*65536 + G*256 + B`、100 分の 1 m）。無効値 `(128,0,0)` は最寄りの有効画素で埋める |
| `texture.png` | 写真タイルを同じ矩形に結合・切り出し |
| `terrain.json` | 範囲・ズーム・実寸・標高の範囲・符号化・出典 |

```json
{
  "bbox": [139.3445, 35.596, 139.3555, 35.605],
  "zoom": 14,
  "size_m": [1002.2, 1009.9],
  "elevation_m": [124.19, 170.33],
  "encoding": "gsi-dem",
  "attribution": "出典: 国土地理院（地理院タイル）"
}
```

`size_m` は `[幅, 奥行]`（m）です。切り出した画素数と bbox 中心の緯度での地上解像度から出すため、
丸めていない bbox ではなく画像の実寸に一致します。`elevation_m` は切り出し内の**有効な**標高画素の
`[最小, 最大]` です（補間した画素は範囲を変えません）。

## 出典表示の決まり

- `terrain.json` の `attribution` は消さず、書き換えない。
- 地形を映像に使うときは、画面またはクレジット・説明欄に
  **「出典: 国土地理院（地理院タイル）」** を表示する。CLI も成功のたびに同じ行を出す。
- 標高の符号化と出典は地理院タイルの利用条件の一部です。出力を変換・再配布するときも
  出典を一緒に持たせてください。

## キャッシュと通信

取得したタイルは `~/.akari/cache/geo/` に保存し、再取得しません（`AKARI_GEO_CACHE_DIR` で変更可）。
同じ bbox と zoom の 2 回目はオフラインでも動きます。取得先は
`cyberjapandata.gsi.go.jp` で、送るのはタイル番号の GET だけです。タイルは 1 枚ずつ取得します。

テストはネットワークに出ません。fetch を差し替え、生成した小さなタイル fixture で
タイル番号の計算・結合と切り出し・無効値の補間・terrain.json の値・タイル数上限・
キャッシュの再利用を検査します。

## 関連

- 写真タイルは JPEG です。AKARI が映像処理で使う ffmpeg の解決経路で展開するため、
  新しい画像ライブラリは足していません。
- `terrain` 宣言そのもの（高さマップ・写真・実寸・誇張を 3D がどう読むか）は 3D 側の担当で、
  このコマンドの範囲外です。
