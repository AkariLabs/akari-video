# 素材ライブラリを育てる

素材・スタイル・テンプレートは、プロジェクトをまたいで再利用できるライブラリとして管理します。
アプリの左のパネルにある「ライブラリ」は、タイムラインへ落とす物の棚が 1 つにまとまったものです。
関わるスキルは 2 つ:
`setup-library`（初期セットアップ。音源ライブラリも含む）・`harvest-asset`（入庫）。

## ライブラリの棚

| 棚 | 中身 |
|---|---|
| 素材 | 音・映像・画像、動く部品、3D・アバターなど。足す（置く / 当てる）物で、ツマミで変えられる |
| スタイル | <!-- F ui.library.captionStyle -->字幕スタイル<!-- /F -->・文字の動き・書体・LUT・つなぎなど。当てる物で、時間を持たない |
| <!-- F ui.library.myStyles -->自分のスタイル<!-- /F --> | 自分で調整して保存したスタイル。「自分のスタイルを保存」から増やす |
| テンプレート | 尺・文字・枠・音が決まったまとまり 1 つ。手元・チャンネル・Lab のものが並び、タイムラインへドラッグして置く（→ [テンプレートを書き出す](#テンプレートを書き出す--akari-template-export)） |
| キットからまとめて入れる | キットに入っている素材をまとめて取り込む |

- 検索の右の「絞り込み」で、出どころ・tier（無料 / Pro）・ライセンス・状態（未取得 / 取得済み）を選べます。
  「商用 OK」「帰属表示あり」でも絞れます
- 各素材には出どころの印が付きます（自分の / Lab / 同梱）。Lab の Pro 素材は、鍵があるときだけ使えます
- 未取得の素材は、使うときに必要な分だけ取得されます。ファイルやフォルダをライブラリへドラッグして取り込むこともできます
- 作り方（Playbook）はライブラリには並びません。ホームの「作り方から」で選びます

## 初回セットアップ — `setup-library`

**いつ使う**: AKARI Video を初めて使うとき。使える素材が足りないとき。

**頼み方**: 「素材ライブラリをセットアップして」「使える素材が足りない」
「BGM を増やしたい」「効果音のライブラリを足して」

1. 必要ツール（ffmpeg・whisper-cli・headless Chrome など）の確認
2. `catalog/`（キュレーション済みカタログ: 3D・音源・B ロール・フォント）から
   スターターパックを提案
3. 承認 → 取得・配置・検証

音（BGM・効果音）のライブラリも同じスキルが受け持ちます。音の経路が、AKARI Sounds の一括取得・
候補リスト・ドロップフォルダ・試聴ギャラリーを扱います（→ [音源を増やす](#音源を増やす--setup-library)）。

承認なしの取得・購入・ログインはしません。ライセンスが確かめられない素材は配置しません。

**置き場所**: 素材は `assets/<カテゴリ>/<id>/` に、由来と使い方の宣言
（`meta.json`）・プレビュー画像とセットで配置されます。カテゴリは**配布物の形**で
6 つです — `overlay`（時間を持つ HTML 断片。画面では「<!-- F ui.library.motionParts -->動く部品<!-- /F -->」）/ `still`（画像に焼く HTML シート）/
`scene3d`（3D モデル + 断片・ベイクレシピ）/ `audio` / `broll` / `font`。テロップ・黒板・
サムネといった主題は tags で引きます。

カタログは**参照配布**です — カタログ自体はリンクとメタデータのみを持ち、
実体は取得時にダウンロード・検証されます。

アカウントで使える素材（無料の素材と、Pro の鍵で使える素材）は、次のコマンドでも直接扱えます。

```sh
akari assets list [--category <c>] [--tag <t>] [--query <s>]
akari assets fetch <category/id> --project .
akari assets show <category/id>
```

一覧の印は、☁ 未取得 / ✓ 取得済み / 🔒 Pro です。

## Lab — 無料と Pro

[Lab](https://akari.video/lab/) は、素材・スタイル・テンプレート・キットの配布先です。
配るものは**無料**か **Pro** の 2 階層だけです。

| | 無料 | Pro |
|---|---|---|
| 使える人 | 誰でも | Lab の Pro（Lifetime）の鍵を持つ人 |
| ライセンス | `CC0-1.0` | `LicenseRef-AKARI-Assets-v0`（単体再配布・再販・他の素材集への再収録は不可） |
| 一覧での見え方 | そのまま取得できる | 鍵のアイコン付きで見える。鍵があれば 1 件ずつ取得できる |

- アプリとの連携は `akari store connect`。ブラウザで AKARI アカウントの接続を承認します
  （接続の状態は `akari store status` で確かめられます）
- 取得済みの素材は、そのまま使い続けられます
- 切り替えより前に CC0 で取得したコピーは、CC0 のままです
- tier とライセンスの規則: [素材 tier 契約 v1](../contract-2026-10-04-asset-tier-v1.md)・
  [素材ライセンスの 2 軸 v0](../contract-2026-09-25-asset-license-axes-v0.md)
  （商用利用と帰属表示は書き出し前に案内されます）

### キットを入れる

キットは、スキル・作り方・テンプレート・素材をまとめて配る束です（契約: [拡張キット v0](../contract-2026-09-13-extension-kit-v0.md)）。

```sh
akari store install <id>
akari store uninstall <id>
```

Lab で無料で配っている作り方の例 10 本（映画・短編ドラマ・MV・解説・商品紹介・Vlog・CM・教育・切り抜き・ロゴ）も、
キットとして入ります。入れると、ホームの「作り方から」の一覧に入手先「Lab」として並びます。

### 素材の英語化

同梱の素材には、`meta.json` の `i18n.en` に英語の名前・説明・使いどころ・ツマミの名前があります。
英語の画面では、これが表示されます（日本語の画面では基底の欄が表示されます）。
自分で入れる素材にも `i18n.en` を足せます。ない欄は基底の日本語の欄に戻ります。

## 音源を増やす — `setup-library`

**頼み方**: 「BGM / 効果音を増やしたい」

`setup-library` の音の経路です。

既定は、公式の **AKARI Sounds**（BGM・ジングル・効果音。無料）を一括で取得する流れです。

```sh
akari sounds              # 一括ダウンロード（mp3）
akari sounds --dry-run    # 取得内容の確認だけ
akari sounds --variant wav
```

公式に無い系統（拍手・失敗音・和風の打撃音など）は、候補リスト HTML で試聴 →
選んだものをドロップフォルダ経由で照合・配置 → 試聴ギャラリーで確認、という半自動フローで足します。
外部のサイトからの取得は、利用者が頼んだときだけ、1 件ずつ行います。

## 成果物を入庫する — `harvest-asset`

**いつ使う**: 案件で作った高コスト・再利用価値の高い成果物
（動く部品・3D・モーション・テロップ・音源・B ロール）を今後も使い回したいとき。

**頼み方**: 「このテロップ、ライブラリに入れておいて」

入庫時に `meta.json`（由来・ライセンス・**調整可能なツマミの宣言**）と
プレビューが付くので、次の案件でエージェントが「何が使えるか・どこを調整できるか」を
機械的に発見できます。生成で簡単に作り直せる物（単純な字幕・色違い・基本のフェード）は入れません。

既定の入庫先はこの手元のライブラリです。公開リポジトリの `assets/`（同梱）へ入れるのは、
同梱すると決めたときだけです。

### テンプレートを書き出す — `akari template export`

音・文字・動き・尺まで作り込んだまとまり（グループ）1 つは、テンプレートとして書き出せます。
`harvest-asset` の入庫とは別の経路です。

<!-- BEGIN GENERATED facts:cli.template -->
```sh
akari template export <project> --item <group-item-id> --id <template-id> [--name <name>] [--out <dir>] [--license-own <license>]
akari template list [--json] [--category <category>] [--tag <tag>] [--channel <channel>]
```

`akari playbook template` は `akari template export` の別名です。
<!-- END GENERATED facts:cli.template -->

配布中の v1.5.0 には `akari template` がなく、`akari playbook template <プロジェクト> --item … --id …` で書き出します。次の版から `akari template export|list` が使えます。旧名は別名として残ります。

書き出したテンプレートは、ライブラリの「テンプレート」の棚に並びます。
棚からタイムラインへドラッグするとまとまり 1 つとして置け、空いている枠（仮枠）へ素材を落とすと、
枠の尺のまま中身が入れ替わります。`akari new --from` からも始められます。
仕様: [テンプレート v0](../contract-2026-10-16-template-v0.md)

## スコープ — どこに置かれるか

| スコープ | 場所 | 用途 |
|---|---|---|
| local | プロジェクト内 `assets/` | この案件だけ |
| shared | 上位ディレクトリ共有（`.akari/assets/`） | 複数案件で共有 |
| user | 作業場の `library/`（作業場が無いときは従来の `~/.akari/assets/`） | 個人の定番 |
| builtin | アプリ・リポ同梱 | 最初から使えるもの |

実際の置き場は `akari assets list` の先頭行で確かめられます。
