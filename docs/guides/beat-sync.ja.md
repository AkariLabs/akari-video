# ビート同期で作る（PV・ショーケース）

カット・オーバーレイ・SFX のすべてを曲の拍にスナップさせ、音に合わせて画面が
動く動画を作ります。スキルは `beat-sync-edit`。

## 向き・不向き

| 向いている | 向いていない |
|---|---|
| 音楽が主で、尺が音源で決まる（PV / ショーケース / ハイライト） | 喋りが主の動画（→ [編集計画を立てて実行する](./plan-your-edit.ja.md)） |
| 切り替えが数十〜数百ある | カット数が少なく手で置ける |

## 仕組み

1. 前提: 対象の曲に [declare-audio](./declare-audio.ja.md) で付けた宣言
   （BPM・頭拍・キメ・区間）があること。宣言なしでは始まりません
2. 生成器スクリプトが、宣言から計算した拍位置ですべてのカット・オーバーレイ・
   SFX の時刻を決め、`edit.json` とオーバーレイ一式を機械生成します —
   手打ちの秒数はどこにもありません
3. 直しは生成器を直して再実行します。`edit.json` は手で編集しません
   （手で直しても次の再生成で消えます）
4. 絵の確認は数秒のミニプロジェクトで回します。フルレンダーだと 1 周 40 分の
   ところが、約 40 秒で確認ループが回ります
