# KF-2 インスペクターのスクロールの保持・プレビュー ⇄ インスペクターのライブ連動 — 実機の証跡

`run-l1.mjs`（検証専用）が一時プロジェクト（1920×1080 / 30fps。下地の動画・図形 box-a / box-b・
位置のキーフレーム付きの図形 box-kf・写真 photo-a・字幕 1 つ）を作り、本物の Electron シェルを CDP で操作して、
インスペクターの `scrollTop`・フォーカス・欄の値、プレビューの要素の矩形、edit.json / captions.json の書き込み回数
（15ms ごとに中身を比べて数える）、スクショを残す。

- `before/` — 基点（統合ブランチの先頭）の開発ビルド。`before.json` + `before-c5.json`（写真の露出だけ別起動）
- `after/` — このブランチの最終ビルド。`after.json`

## a. スクロールとフォーカスの保持（box-a を選んだまま）

| 操作 | 基点 | このブランチ |
|---|---|---|
| scrollTop=420 → プレビューで図形をドラッグして離す | 420 | **420**（書き込み 1 回） |
| scrollTop=420 → 枠の太さに打ち込んで Enter | 420 | **420**（書き込み 1 回） |
| scrollTop=120 → X に打ち込んで Tab | **0**・フォーカスが消える | **120**・フォーカスは Y・書き込み 1 回 |
| scrollTop=420 → 別の item（box-b）を選ぶ | 420（先頭へ戻らない） | **0** |

## b. プレビュー → インスペクター（ドラッグの最中）

| 操作 | 基点 | このブランチ |
|---|---|---|
| 移動（8 歩） | X・Y は 300 / 200 のまま。離すと 902 / 440 | 390 → 420 → 502 → 602 → 660 → 752 → 810 → 902（Y も追従）。途中の書き込み 0 回・離して 1 回 |
| 右下のつまみ（6 歩） | 拡縮 100 のまま | 117 → 136.3 → 155.6 → 174.9 → 194.1 → 213.4。書き込み 1 回 |
| 回転（6 歩） | 回転 0 のまま | −12.35 → −21.79 → −28.88 → −34.25 → −38.39 → −45。書き込み 1 回 |
| キーフレーム付き box-kf を 5 秒で移動 | X は 1120 のまま | 860 → 960 → 1060.99 → 1176.65 |

## c. インスペクター → プレビュー（スクラブ・スライダー・入力の最中）

| 操作 | 基点 | このブランチ |
|---|---|---|
| X のスクラブ（9 歩・X 320→480） | プレビューの左端 87.9 のまま。離すと 119 | 91.3 → 94.8 → … → 119（1 歩ごと）。途中 0 回・離して 1 回・undo 1 回で元へ（`after-c1-scrub-3/6/9.png`） |
| Y のスクラブ中に Esc | 動かない | 上端 91.7 → 117.6（スクラブ中）→ Esc で 91.7。書き込み 0 回（`after-c2-esc-*.png`） |
| X に 900 と打ち込む途中 → Enter | 打ち込み中は動かない | 打ち込み中に動く・Enter で 1 回・undo 1 回で元へ |
| 字幕の大きさスライダー（3 歩） | 38px のまま。離すと captions.json に 1 回 | 78px → 94px → 125px。途中 0 回・離して 1 回・undo 1 回（`after-c4-captions-range0-1/2/3.png`） |
| 写真の露出のスクラブ（3 歩） | 写真の平均の明るさ 97.96 のまま。離すと 102.43 | 99.87 → 101.39 → 102.43。途中 0 回・離して 1 回・undo 1 回（`after-c5-photo-adjust-1/2/3.png`） |
| キーフレーム付き box-kf の X のスクラブ（5 秒） | 動かない | 左端 214.1 → 219.3 → 224.5 → 229.7（再生位置でその値の見た目） |

## d. 回帰

| 項目 | このブランチ |
|---|---|
| 写真の選択（プレビューで押す） | タイムラインとインスペクターが photo.png |
| 消しゴム | `aria-pressed="true"`・なぞって `erase[]` 1 本・書き込み 1 回・undo 1 回で元へ |
| 右下のつまみ（box-b） | 左上のずれ (0, 0)・書き込み 1 回・undo 1 回で元へ |

## 残っていること

- `z-diag`（スクロールの書き込みのログ）: X → Tab の後、最終の位置は 120 に戻るが、読み直しの途中に約 25〜45ms だけ
  scrollTop=0 が書かれる（`after.json` の `z-diag.after.log`）。一瞬先頭へ跳んで戻るちらつきとして見える可能性がある
- 図形のつまみの値（塗り・線の太さ・角丸）・写真の露出以外の調整・行間などの字幕の他のスライダーは、ライブの一時の上書きに未対応（確定時の 1 回の書き込みで反映）
