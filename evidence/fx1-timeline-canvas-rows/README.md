# evidence: fx1-timeline-canvas-rows（タイムラインのキャンバスの見せ方）

実機確認で見つかった 3 点の修正の実機（L1）証跡。

1. 段をまたいで同じ時刻に 3 個以上あると「同じ時刻に N 個」の 1 行へ自動で畳まれ、わかりにくい
   → 自動の畳みをやめ、重なっても普通にトラックごとに並べる。キャンバスは「キャンバスにする」を押したときだけ
2. 写真 2 枚（image-1・空の枠）を選んで「キャンバスにする」と、キャンバスの行を畳んでいるときは 2 つが
   トラック名の行（外の行）に描かれ、開くとキャンバスの子の行に描かれる（`edit.json` の所属と表示が合わない）
   → 畳んでいるときはキャンバスの帯の上の細い印だけ、開いたときは子の行だけに描く
3. キャンバスの行の見出しの帯が太い → 字幕の行と同じ高さ

production ビルドの Electron を隔離 `--user-data-dir` / `THEIA_CONFIG_DIR` / `AKARI_HOME` +
`--remote-debugging-port` で起動し、生 CDP で実マウス・実キー（クリック・Shift+クリック・⌘G・⌘Z）を投げて
`edit.json` とタイムラインの DOM（左の見出しの行・帯の上のチップの矩形）を読む。
共通部品 `scripts/l1-lib.mjs` は `c0b-canvas-ui` のものの複製（起動するチェックアウトを `AKARI_L1_REPO` で差し替えられる）。

```sh
cd apps/shell && npm run build
AKARI_CDP_PORT=<port> AKARI_L1_LABEL=before AKARI_L1_REPO=<基点のチェックアウト> node evidence/fx1-timeline-canvas-rows/scripts/l1-fx1.mjs
AKARI_CDP_PORT=<port> AKARI_L1_LABEL=after node evidence/fx1-timeline-canvas-rows/scripts/l1-fx1.mjs
```

fixture（1 プロジェクト）: 本編 `clip.mp4`（30 秒）/ 5 秒に図形 3 個（棚の四角・丸・四角、`buildShapeItem` で作る、段 s1〜s3）/
15 秒に写真 2 枚（image-1 = 段 p1、空の枠 frame-1 = 段 p2）/ 字幕 1 件。素材（mp4・png）は ffmpeg の lavfi で一時ディレクトリに
都度生成し、終了時に削除する（バイナリはコミットしない）。`observations.json` のパスは `<REPO>` / `<TMP>` / `<HOME>` に置き換えてある。

## BEFORE（基点 75033ab3・`before/`）

| 観測 | 結果 |
|---|---|
| 同じ時刻の図形 3 個 | 「同じ時刻に 3 個」の 1 行に畳まれ、3 個のチップは帯に出ない（`01-initial.png`） |
| image-1 と空の枠を選んで ⌘G | キャンバス g-1（段 p2・450 フレーム・子 2 個）ができる |
| 畳んでいるとき | 2 つのチップが **トラック名 V5 の行** に描かれ、下のキャンバスの行（g-1）は空（`02-canvas-collapsed.png`） |
| ▸ で開いたとき | 2 つはキャンバスの子の行に描かれる（`03-canvas-expanded.png`） |
| 行の高さ | キャンバスの行 48px / 字幕の行 24px（キャンバスの帯 48px） |
| 1 つ出す → ⌘Z 1 回 → ⌘Z 1 回 | 絶対時刻 450 のまま段直下へ / 出す前に戻る / 「キャンバスにする」の前に戻る |

## AFTER（`after/`・9 項目すべて PASS）

| # | 受け入れ条件 | 実測 |
|---|---|---|
| 1 | 同じ時刻に 3 個 → 見出しが出ない | 「同じ時刻に N 個」の文字 0 件（`01-initial.png`） |
| 2 | 3 つのトラックに普通に並ぶ | shape-1 / 2 / 3 がそれぞれ V2 / V3 / V4 の行に 1 つずつ |
| 3 | 2 つを選んで ⌘G | キャンバス g-1・子 image-1 / frame-1・絶対時刻 450 のまま |
| 4 | 畳んでいるとき、外の行に出ない | 2 つの通常チップは 0 個。キャンバスの帯（g-1 の行）の上に子の印（高さ 2px）が 2 つだけ（`02-canvas-collapsed.png`） |
| 5 | 開いたとき、キャンバスに属して見える | 2 つのチップはそれぞれ image-1 / 空の枠 の子の行（48px）に描かれる（`03-canvas-expanded.png`） |
| 6 | キャンバスの行の高さ ≒ 字幕の行 | キャンバスの行 22px・帯 22px / 字幕の行 24px（普通のトラック 50px・開いたときの子の行 48px） |
| 7 | 出し入れで時刻を保つ | 子の行の右クリック「キャンバスから出す」→ 段直下・絶対時刻 450 |
| 8 | undo 1 回（出す） | ⌘Z 1 回で出す前の `edit.json` と一致 |
| 9 | undo 1 回（キャンバスにする） | もう 1 回の ⌘Z で「キャンバスにする」の前の `edit.json` と一致 |

起動した Electron は終了時にプロファイルを握るプロセス 0 件を確認している（`leftoverProcesses`）。

## 注記

- ⌘G は CDP の実キー（Meta + g）で送っている。右クリック「キャンバスにする」の経路は本証跡では通していない（ドライバには
  ⌘G が効かなかったときの予備として残してある）
- 畳んだときの子の印は、固定尺のキャンバスの区間の外にはみ出す部分を切り詰めて描く（単体テストで確認）。実機では区間内の子だけを確認した
- 書き出し（render-cut）には触れていない（表示だけの変更）
