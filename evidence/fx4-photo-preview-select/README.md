# FX-4 プレビューで見えている写真を選ぶ — 実機の証跡

`run-l1.mjs` が一時プロジェクトを作り、本物の Electron シェルで押す・つまむ・なぞるを行って、
押した点・選ばれた id（プレビューの選択枠とタイムラインの `.akari-annotations-selected`）・
edit.json の transform / erase / mask・履歴の件数・スクショを残す。

## 一時プロジェクト（1920×1080 / 30fps）

| id | 中身 | 位置（出力 px） |
|---|---|---|
| cut-1 | 下の動画（testsrc2 の 10 秒） | 画面いっぱい |
| photo-a | 被写体のある写真（640×360 JPEG・`c0a-group-media-render` の検証用画像） | 350〜1070 × 287〜692 |
| photo-b | 青の写真（800×600 PNG・**左 1/4 が透明**）。A の上のトラック | 700〜1420 × 370〜910 |
| box | 図形（紫の四角） | 1500〜1800 × 80〜280 |
| photo-lib | ライブラリの写真（プロジェクトの assets に無く、参照台帳でライブラリの置き場へ読み替える） | 280〜640 × 90〜330 |
| canvas-1 / photo-in-canvas | キャンバス（`source.kind: group`）の中の写真 600×600 | 110〜410 × 720〜1020 |

## BEFORE（基点の開発ビルド・`before/`）

| 押した所 | 期待 | 基点 |
|---|---|---|
| B の不透明な所 | photo-b | photo-b |
| **B の透明な所（下に A）** | **photo-a** | **photo-b**（透明でも前の写真が取る） |
| A だけの所 | photo-a | photo-a |
| 写真の外 | cut-1 | cut-1 |
| 図形 | box | box |
| **キャンバスの中の写真** | 写真・タイムラインも同期 | プレビューの枠だけ付き、**タイムラインの選択は空** |
| カットを選んだ状態から B | photo-b | photo-b |

- 消しゴム: 押しても**ボタンの見た目は変わらない**（`aria-pressed` なし）・プレビューに状態の表示なし・カーソルは十字のみ。なぞると線は書かれ、undo も 1 本ずつ戻る（この fixture では写真への当たりは取れていた）
- 背景を消す: 開発ビルドでは補助が作られず「**この Mac では使えません**」（`apps/shell/native/bin/` が無い）
- オーナーの報告の「下の動画が選ばれる」の 1:1 の再現は、この fixture（読み込み済みの写真）では起きなかった。
  原因はコードの読みで特定した: 画像のレイヤーは読み込みが終わるまで `display:none` になり、当たり判定が
  非表示のレイヤーを候補から外すため、描画エンジン側に写真が出ていても下の動画が選ばれる

## AFTER（このブランチの最終ビルド・`after/`）

| 項目 | 実測 |
|---|---|
| B の不透明な所 / 重なりの不透明な所 | photo-b（タイムライン `layer:photo-b`） |
| B の透明な所 | **photo-a**（素通し） |
| A だけの所・ライブラリの写真 | photo-a / photo-lib |
| 写真の外 / 図形 / カットを選んだ状態から B | cut-1 / box / photo-b |
| キャンバスの中の写真 | タイムラインがキャンバスを開いて子の行 `item:photo-in-canvas` を選ぶ。インスペクターに写真の欄 |
| 右下の角 | 左上のつまみ **(0, 0) px**・縦横比 1.3334 → 1.3333・undo 1 回で edit.json がバイト一致に戻る |
| 右 / 左 / 下の辺 | 反対側の辺のつまみ **(0, 0) px**・`scaleX` / `scaleY` に書く・undo 1 回でバイト一致 |
| 移動・回転 | transform に書かれ、undo 1 回でバイト一致 |
| キャンバスの中の写真の移動・右下の角 | 入れ子の item の transform に書かれる（左上 (0, 0) px）・undo 1 回 |
| 段の下端の写真の回転 / 移動ボタン | 浮いたメニューと重ならない所（枠の内側の下端）に出て、押して動かせる |
| ダブルクリック | 切り抜きモードに入る（F-1a の経路）・Esc で抜ける |
| 消しゴム | `aria-pressed="true"`・「消しゴム中 — Esc で終わる」・ブラシの大きさの円のカーソル（8.2px = 大きさ 5% × 写真の短辺 × 段の縮尺）。なぞると `erase[]` に 1 本ずつ。2 本 → undo 1 回で 1 本 → もう 1 回で 0 本。Esc・ボタンをもう一度押すで終わり `aria-pressed="false"` |
| 背景を消す | `npm run build` の後に `apps/shell/native/bin/akari-photo-mask` ができ、被写体のある写真で `assets/masks/<sha256>.png` と `mask` が書かれ「背景を消しました。」 |

## H-1 の回帰（`h1-regression/`）

`evidence/h1-handles/run-l1.mjs` を最終ビルドで流した（シナリオどうしの干渉を避けて一部は別起動）。
図形の右下の角 = 左上 (0, 0)・カットの角 = 左上 (0, 0)・30° の図形の辺 = 左の辺 (0, 0)・文字の辺 = 折り返し幅・
回転 = 45° に吸い付き中心 (0, 0)・ガイド = 差 0・ライン 45°・Shift (41.5, 0)・⌘ = 吸い付かない 3px・⌥ = 複製・
後ろの要素のつまみ・余白で解除。どれも H-1 の合格値と同じ（`summary.json`）。
