# F-1b ラッパーの L1 実機確認（開発ビルド・Electron）

検証用の写真は、F-0 と同じ「実在しない人物の生成画像」を左右に 2 人並べ（右は左右反転・色味を変えたもの）、中央に図形で描いた赤いマグを置いた 1920×1080 の合成画像。下に単色の緑（sRGB 40,200,90）の静止画、上に写真を置いた 1920×1080 / 30fps の一時プロジェクトで確認した。Vision の人物インスタンスでは右の人物が「人物 1」、左が「人物 2」。

| 画像 | 確認したこと |
|---|---|
| 01-cutout-window-over-inspector.png | 背景透過の窓がインスペクターの領域の上に開き、プレビューを覆わない。「人物だけ」で 人物だけ / 人物 1 / 人物 2 の候補 |
| 02-hover-highlight.png | 「写っているものを押す」の間、プレビュー上の右の人物にポインタを乗せると候補が光る（選択枠は `akari-photo-pointer-mode`・`pointer-events: auto`） |
| 03-click-selects-person1.png | プレビューの右の人物を押すと窓で「人物 1」が選ばれる。もう一度押すと外れ、さらに押すと再び選ばれる |
| 04-keep-person1-applied.png | 「選んだものを残す」→ 人物 2 とマグが消える。窓は開いたまま「適用しました」 |
| 05-feather-0-vs-30.png | なめらかさ 0（左）と 30（右）。境界だけがやわらかくなり、内側の画素は同じ値（`maskFeather: 30` を書き込み） |
| 06-area-select-window.png | 「エリアを選択」の窓（画像全体 / 人物 1 … / 背景・調整・ぼかし・フィルター） |
| 07-person1-bright-bg-mono-with-cutout.png | 人物 1 = 露出 +1.5、背景 = モノクロ。人物 1 は明るく色のまま（背景透過中なので背景は見えない） |
| 08-person1-bright-bg-mono-no-cutout.png | 同じ regions のまま切り抜きの `mask` だけ一時的に外した状態。人物 1 は明るく色のまま・背景（壁とマグ）はモノクロ・人物 2 は前景なので元のまま。同時に成り立つ |
| 09-after-cache-delete-restart.png | `.akari/cache/` を消して Electron を再起動しても同じ絵 |
| 10-eraser-mode.png / 12-eraser-stroke.png | 窓の「消しゴムで直す」→ F-0 のブラシ（十字カーソル）。プレビュー上でなぞると `erase[]` に書き込まれ、その部分が消える |
| 11-preview-gpu-osr-grid.png | 上段 = 背景透過あり、下段 = 切り抜きなし。左からプレビュー・GPU 書き出し・OSR 書き出し（15 フレーム目）。GPU と OSR の PSNR は 44.7 dB / 42.1 dB |

- 画面の緑の色味の違いは、スクリーンショットのディスプレイ色空間（プレビュー）と mp4（BT.709）の違い。書き出しの緑は 40,200,90 のまま
- 人物 1 のマスクはマグの位置で最大 4/255 の弱い値を持つ（Vision の出力）。書き出しのマグ位置の画素は緑から最大 2 階調のずれで、見た目には出ない
