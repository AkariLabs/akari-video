# 既存素材のライセンス導出

`assets/` と `catalog/` の `meta.json` 67 件を導出関数へ通した。商用利用が `unknown` になるものは次の 7 件。元データは変更していない。

- `catalog/font/ab-kirigirisu/meta.json`
- `catalog/font/kso-kokuryuso/meta.json`
- `catalog/font/ta-engeifude/meta.json`
- `catalog/font/ta-f1-blockline/meta.json`
- `catalog/font/ta-fugafude/meta.json`
- `catalog/font/vdl-logojr-black/meta.json`
- `catalog/font/vdl-v7-mincho/meta.json`

いずれも `LicenseRef-proprietary` / `paid-license-required`。使用条件を確認したうえで商用利用の可否を明示する。推測で `allowed` にしない。
