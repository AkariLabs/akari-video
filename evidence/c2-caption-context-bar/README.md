# C-2 字幕のメニューの作り直し — 実機の証跡

`run-l1.mjs`（検証専用。下地は B-1 の `evidence/b1-context-bar/run-l1.mjs`）が一時プロジェクト
（1920×1080 / 30fps。下地の動画・写真 1 枚・図形 1 つ・字幕 2 つ = `fixtures/`）を作り、本物の Electron シェルを CDP で操作して測る。
筋書きは `scenarios.mjs`（BEFORE）と `scenarios-after.mjs`（AFTER）。書き込みは edit.json と captions.json の中身を 15ms ごとに見て、変わった回数を数える。

- `before/` — 基点のビルド。`before.json`
- `after/` — このブランチの最終ビルド。`after.json`

## 下の道具バー

- 吸着 ON → OFF → ON（2 回とも）・はみ出し防止 OFF → ON → OFF・この字幕だけ動く ⇄ 全字幕が動く。どれも書き込み 0 回（表示の切り替え）
- 字幕をドラッグで動かす（書き込み 1）→「位置と大きさを既定に戻す」が出る → 押す（書き込み 1）→ 字幕固有の位置が消える（`after-bottom-after-move.png` / `after-bottom-after-reset.png`）

## 「…」

- 上のメニューの末尾の「…」→ マイスタイルに保存・インスペクターを開く（`after/after-more-open.png`）
- マイスタイルに保存 → 保存の窓が開く（開くだけでは書き込み 0 回。`after-more-mystyle-save.png`）
- インスペクターを開く → インスペクターの字幕（テキストのタブ）が出る（`after-more-inspector.png`）
