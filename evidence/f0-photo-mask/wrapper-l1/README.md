# 写真マスク v0 — ラッパーによる実機確認（L1）

検証用の人物写真は、実在しない人物の生成画像（1024×1536・暗い背景）。下に単色の緑（sRGB 40,200,90）の静止画、上に写真を置いた 1080×1920 / 30fps の一時プロジェクトで確認した。

## BEFORE（インストール済み v0.1.82）

- 写真に手書きの 8bit グレー PNG マスクを `mask` で指定 → プレビューのログに `layers[0].mask を無視しました（静止画には対応していません）`。マスクは適用されない（`00-before-installed-mask-ignored.png`）。

## AFTER（このブランチの開発ビルド）

| 項目 | 結果 |
|---|---|
| 背景を消す（この Mac で） | `assets/masks/<sha256>.png`（8bit グレー・1024×1536・ファイル名 = 内容の SHA-256）と `.meta.json`（inputSha256 = 写真の SHA-256・engine apple-vision・request foreground-instance）ができ、edit.json に sources と `mask` が 1 回の書き込みで入る。マスク画素: 人物中心 (0.5,0.35)(0.5,0.5) = 255、四隅 = 0 |
| 消しゴム | 「戻す」1 本（背景の左上）・「消す」1 本（胸）。どちらも edit.json の `erase[]` に 1 本ずつ・履歴 1 件ずつ |
| 左右反転 + 切り抜き（左 15%・幅 70%） | 線は写真と一緒に動く（`03-flip-and-crop-strokes-follow.png`） |
| 期待位置の色（素材座標 → 切り抜き・反転後の画面座標を計算） | 戻した所 = 写真の黒（10〜11）、その 60px 下 = 背景の緑、消した所 = 背景の緑、その 60px 下 = シャツ、写真の角 = 背景の緑、顔 = 肌色。プレビュー・GPU・OSR の 3 経路とも一致 |
| キャッシュ削除 + 補助を隠して再起動 | 読み込み中の外部通信 0 件（ローカル 18 件のみ）。再起動を 2 回挟んだ全画面プレビューの画素差 **最大 1・平均 0.000**（2240×1336） |
| 書き出しとプレビュー | 全画面プレビューの舞台（650×1156）を P3→sRGB に変換して比較（画面キャプチャは表示の色空間 Display P3 で撮れるため）。GPU: 最大 41・平均 2.03（8 超の画素 0.7%）/ OSR: 最大 31・平均 2.08（0.6%）。差は縮小・H.264 の圧縮・マスク境界の縁に集中 |
| GPU と OSR | 1080×1920 の 15 フレーム目: 最大 38・平均 0.87 |
| 補助が無いとき | 「この Mac では使えません」の通知。アプリは落ちず edit.json も不変（`05-helper-missing-message.png`） |

## 確認できなかったこと

- 背景を消す・線・反転それぞれの **undo の実機確認**。確認の途中で macOS の WindowServer が再起動し、以後この検証セッションから GUI アプリも書き出しも起動できなくなった。履歴（`.akari/history`）には操作 1 回ごとに 1 件ずつ記録されていること、誤操作の移動を undo 1 回で戻せたことまでは確認済み。

## 再開後の確認（上の「確認できなかったこと」の解消）

同じ一時プロジェクトを初期状態（写真にマスクなし・履歴なし・`assets/masks/` なし）へ戻し、第 3 往復の修正を入れた開発ビルドで取り直した。

| 項目 | 結果 |
|---|---|
| マスク欄の表示 | 背景を消した直後の選択欄は「背景を消したマスク」。id（`mask-<sha256>`）は edit.json の値のままで画面には出ない（`08-mask-label-plain-words.png`） |
| 操作ごとの edit.json | S0 初期 → S1 背景を消す（sources + mask）→ S2「戻す」1 本 → S3「消す」1 本 → S4 左右反転。履歴は 1 操作 1 件（計 4 件） |
| undo 1 手ずつ | タイムラインの「元に戻す」を 1 回押すごとに edit.json が 1 つ前の状態と**バイト一致**: 1 回目 = S3（反転が外れる）/ 2 回目 = S2（消す線が消える）/ 3 回目 = S1（戻す線が消える）/ 4 回目 = S0（マスクと sources の項目が外れる）。プレビューも同じ順に戻る（`09-undo-one-step-each.png`、左から S4・undo 1〜4 回目） |
| redo | 「やり直す」4 回で S1 → S2 → S3 → S4 とバイト一致で戻る |
| 書き出しとプレビュー（S4） | 全画面プレビューの舞台 650×1156 を P3→sRGB に変換して 15 フレーム目と比較: GPU 最大 41・平均 2.03（8 超 0.7%）/ OSR 最大 31・平均 2.08（0.6%）。GPU と OSR 同士は 1080×1920 で最大 36・平均 0.88。戻した所 = 写真の黒（10,10,12）・消した所 = 背景の緑（38,198,89）が両経路で一致 |
