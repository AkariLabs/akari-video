# 写真マスクの実機確認

- 512×288 の人物写真と保存済み 8bit グレー PNG を持つ一時プロジェクトを Electron で開いた。プレビューで背景透過、消去と復元の線、切り抜き、左右反転を確認した。
- GPU と OSR の書き出しは各 150 フレームを完走した。同じフレームを RGBA に復号した差は最大 50、平均 0.917（全チャンネル平均）。プレビューの表示領域を 512×288 に正規化して比較した差は GPU が最大 62・平均 1.289、OSR が最大 62・平均 1.245。後者には画面表示の縮尺変更と動画圧縮による差が含まれる。
- キャッシュを削除し、補助を一時的に見えなくした状態でアプリを再起動した。外部通信の背景処理も無効にして開き、同じマスクと線、反転を表示した。再起動前後の表示領域を 512×288 に正規化した差は最大 22・平均 0.235。表示領域の実寸は再起動前後で異なったため、これは同一出力画素の厳密比較ではない。
- 補助の出力を保存処理へ渡すと、ハッシュ名の PNG と同名の由来ファイルができた。同じ入力で再実行すると同じ参照名を返し、既存ファイルを置き換えなかった。
- 現行 edit-lint は静止画 PNG マスクに `v2.mask-video` エラーを出す。該当判定は所有範囲外にあり、通常の書き出しはここで止まる。上記の一時プロジェクトの書き出し検証では明示的に検査の門を越える設定を用いた。
- ラッパーが L1 を取り直す。
