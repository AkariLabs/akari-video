# akari-chat-review — L1 検証スクリプト

プレビューのペン / ピン / 範囲 / 添付を、production ビルドの Electron + CDP + 実 DOM（実マウス・実キー）で確かめる。
道具は再生バーの 2 行目、入力と一覧はバーの下の置き場（`#review-dock`）に 1 つだけ出る。

```sh
cd apps/shell && npm run build
cd ../.. && AKARI_L1_OUT=<リポの外の出力先> node apps/shell/extensions/akari-preview/evidence/akari-chat-review/run-l1.mjs
```

- 一時ディレクトリ（ホームの外）に HOME / TMPDIR / プロファイル / プロジェクトを作って隔離する。
  プロジェクトはテンプレート + ffmpeg 合成素材 + `captions.json` の字幕 1 件 + `exports/draft-v1.mp4`
- 自分で起動した Electron だけを使い、終わったらその PID だけを止める。CDP のポートは空いている番号を OS から取る
  （`AKARI_CDP_PORT` で上書き可）。パートナーの CLI は起動しない
- `AKARI_L1_SECTIONS` で流す節を絞れる（カンマ区切り・既定は全部。後ろの節は前の節が作った印を使う）

| 節 | 確かめること |
|---|---|
| `layout` | 道具の 4 つのボタンが 2 行目（1 行目の `.transport-right` には足さない）・文字のラベルなし + `title` / `aria-label`・1 行目のアイコンのボタンと同じ大きさ・2 行目の高さと 1 行目との隙間・置き場は閉じると高さ 0・案内は 2 行目の左・選んだ道具はオレンジ・範囲の「開始」「終了」は 2 行目の中 |
| `pin` | ピンを打った瞬間に番号のバッジと pending.json の 1 件（メモは空）・置き場に入力が開いてフォーカスが入る・入力はステージと重ならない・置き場の中央の `elementFromPoint`・続けて 2 個目 3 個目・番号を押して直す（印は増えない）・Shift+Enter = 改行・変換中の Enter では保存しない・Enter = 保存して閉じる・Esc の順番（付けたばかりで空の印は消える / メモのある印と前からある空の印は残る）・入力の中のスペース / ← / 1 / ⌘Z が再生・コマ送り・host のキーバインドへ漏れない・番号を押した直後のクリックが 1 回で効く・変換中の Esc では閉じない・フォーカスが外れたら保存 |
| `pen` | 囲むと番号 + 置き場の入力（囲んだ場所には出ない）・「ここにあるもの」にテロップの文字・丸は描いた位置に出る・入力は 1 行（頭に番号・道具・時刻 / 右端に削除・完了のアイコンのボタン） |
| `range` | 範囲を決めると印ができ、入力の頭に `0:03〜0:05`・決めた直後に再生位置が動かない・シークバーの点・時刻が離れた印は薄く、押せない |
| `tray` | 添付のボタン → 置き場に一覧（入力は閉じる）・ステージと重ならない・上限 `min(40vh, 220px)`・行は 番号 / コマの絵 / 時刻・道具・メモ / ×・メモが空なら「メモなし」・見出しと「あとで」が無い・行を押すとその印の入力（離れた時刻はシークしてから）・入力と一覧が同時に見えている瞬間が無い・× で外す |
| `geometry` | 置き場を開く前後と、窓の大きさを変えた後で、番号 1 のバッジの中心が絵（映像の枠）の同じ場所にある（差 0.5% 以内） |
| `chrome` | 道具なしのステージのクリックは今までどおり絵の要素を選ぶ・置き場の開閉に、選んだ要素の枠が追従する（対照として窓の大きさの変更も測る） |
| `themes` | 暗い / 明るいテーマで 2 行目・入力・一覧の画像（6 枚）と、文字と地のコントラスト |
| `restart` | アプリを落として開き直しても、印とメモが残る・これまでの形の pending.json（id の無い印）もそのまま読めて直せる |
| `attach` | 「クリップボードにコピー」で渡した文章に、メモが空の印が壊れずに入っている・渡したあと空になる・コマの絵の保存 |
| `export` | 書き出した動画（`exports/*.mp4`）のプレビューでも、2 行目とピン → 入力が同じに動く |

- `attach` の節は**システムのクリップボードを書き換える**。始める前の文字を取っておき、終わったら戻す（文字以外の中身は戻らない）
- 結果 JSON とスクリーンショットは `AKARI_L1_OUT` に出す。リポにはコミットしない
