# 置いた文字の実機所見 5 点 — L1 証跡

実機の Electron を専用のポート・一時ディレクトリ・専用 `AKARI_HOME` で起動し、CDP の実マウス・実キーで操作して実測した。
fixture は `scripts/gen-fixture.mjs`（話した言葉 8 行 + 置いた文字 9 本・`mc` アンカー・1280x720・32 秒）。
実行: `node scripts/gen-fixture.mjs <dir>` → `node scripts/l1.mjs before|after <dir> [--port=9447]`。

- `results-before.json` / `before-*.png` — 変更前ビルド（origin/main 相当）の観測記録（判定なし）
- `results-after.json` / `after-*.png` — 変更後ビルドの判定つき実測（17 項目すべて pass）

BEFORE の記録のうち「話した言葉の字幕」の 2 項目と「台本の T ボタン」は、当時の検証スクリプトの不備（プレート id の引き当て・行の選択点）で測れていない。AFTER はスクリプトを直した後の値。

| 再読込後も同じ位置 | Electron を起動し直して誤差 -0.0001 / 0 |
| 話した言葉の字幕は従来どおり | 中央付近へのドラッグで `x` を持たない（中央揃え）。フレーム外へのドラッグははみ出し防止で枠内（右端 0.9233） |
| 置いた文字のはみ出し防止 | 選択中のチップが「🧲 はみ出し防止 OFF」（既定 OFF） |

描画系の `mc` アンカーは「`x` = プレートの左端・`y` = 縦の中心」として描く（BEFORE でも初期値 `x: 0.5` の文字は左端がフレーム中央に来る）。
そのため保存値の期待値は「落とした中心 − プレート幅の半分」で、描画位置の期待値は落とした中心そのもの。
