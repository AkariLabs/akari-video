## 判定から外れた 1 項目（右端のドラッグ）

「5 か所へドラッグ」の右端（落とした中心 x = 0.86）で、描画された中心が 0.8447（誤差 -0.0153）、続く下端付近で +0.0153 となり、±1% の判定から外れた。3 回とも同じ。

- rebase 前の AFTER 走行でも同じ縮みが出ている: AFTER の下端付近の保存値 0.0417 は「右端から持ち上げたときの幅 0.1965」で計算した値。AFTER で右端が合格したのは、測った時点ではまだ縮む前だったため（計測の時機の差）
