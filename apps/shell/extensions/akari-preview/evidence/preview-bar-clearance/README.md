# 出力プレビューの上のメニューが映像に重ならないように + 2 本指パン — 実機の証跡

`run-l1.mjs`（検証専用。下地は C-2 の `evidence/c2-caption-context-bar/run-l1.mjs`）が一時プロジェクト
（`fixtures/landscape.json` = 1920×1080 / `fixtures/portrait.json` = 1080×1920。下地の単色動画・写真 1 枚・図形 1 つ・字幕 2 つ）を作り、
開発ビルドの Electron を専用の userData / `AKARI_HOME` / `THEIA_CONFIG_DIR` で起動して CDP で操作・計測する。
筋書きは `scenarios.mjs`（BEFORE / AFTER 共通）と `scenarios-after.mjs`（AFTER だけ: 選び直しの時系列・再生中・P-1 のドロップ）。

- 座標はすべて本体ページの CSS px。「上のメニューの下端」= `[data-akari-ui="preview-context-bar"]` の下端、「映像の上端」= webview の `#preview-stage` の上端 + iframe の位置
- 2 本指スクロール = `Input.dispatchMouseEvent` の `mouseWheel`（修飾なし）、ピンチ = 同じく ctrl 付き
- プレビューの iframe は約 404×359（ウィンドウ 1120×668 相当・右にインスペクター）
- `before/` = 基点 `5e38b7a87` のビルド、`after/` = このブランチの最終ビルド。`<label>-<aspect>.json` が数値の全体

## 選び直し・解除・再生中（AFTER・`reselect-timeline` / `playing`）

- 字幕 → 図形 → 字幕と選び直しても映像の上端は 1 値のまま（縦長 127 / 横長 132.1。サンプル 40ms 間隔）
- 解除（Escape）から約 1.07 秒は保ち、その後 約 130〜140ms で元の位置へ（縦長 127 → 118.6 → 85.9 → 65.9 → 57.2 → 55）
- 字幕を選んで再生 → 再生中に解除: 1.8 秒間 動かない（127 / 132.1 のまま）→ 一時停止すると戻る（`after-*-playing-then-paused.png`）
  出力プレビューの上をクリックすると再生が止まるため、「再生中に選ぶ」は操作として作れない。解除の側で確かめた
