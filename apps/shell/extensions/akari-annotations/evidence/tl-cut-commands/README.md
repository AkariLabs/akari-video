# 証跡: タイムラインのカット操作 — I / O の範囲・詰めて消す・Q / W・⌘B・隙間の選択・自動で詰める（2026-10-06-tl-cut-commands）

検証はラッパーが実施（実機 = 専用の CDP ポート 9465・一時ディレクトリの `--user-data-dir` / `THEIA_CONFIG_DIR` / `AKARI_HOME`・一時 workspace）。
ウィンドウは 1440×900（CSS px）、左右のパネルを畳んだ配置。記録物（JSON・PNG）はリポの外に置き、ここには再現用のスクリプトだけを置く。

## fixture と手順

- `scripts/gen-fixture.mjs <リポ外の出力先>`: 20 秒・30fps。本編（`main`・`audio: false`）+ リンク音声（`main-audio` → `main`）、
  テロップ（HTML 素材・7〜13 秒と 15〜17 秒）、B ロール（7〜13 秒と 15〜18 秒）、効果音（7〜13 秒と 15〜17 秒）、BGM（全長・`role: bgm`）、
  字幕 2 行（9〜11 秒・15〜17 秒、本編に追従）。素材は ffmpeg で作る（L1 専用）。edit-lint は PASS（警告 1 = `geometry.fit-compat`）
- `scripts/verify.mjs <apps/shell> <project> <isoDir> <recordDir>`: 実マウス / 実キー（CDP `Input.dispatch*`）で受け入れ条件を 1 項目ずつ操作し、
  edit.json と画面（範囲の帯・札・隙間の枠・メニュー・字幕チップ・インスペクター・左右パネル・ステータスバー）を `verify.json` に採る。
  各段のあとは Cmd+Z で基点へ戻し、byte 一致を確かめる。`STEPS=a,b` で段を絞れる。`--port` は 9465 固定
- `scripts/launch.mjs`: 起動して止めておく（手で観察するとき用。止めるのは表示された PID だけ）

ビルド: `packages/edit-store` を `npm run build` してから `apps/shell` を `npm run build`（shell のビルドは edit-store の実行時コードを作り直さない）。

## 実測（AFTER・`verify.json`。フレーム表記は `id@at+duration`、30fps）

| 確認 | 結果 |
|---|---|
| 8 秒で I・12 秒で O | 帯（ルーラー・トラック領域）と上下いっぱいの線が 8 / 12 秒に出る。札「I 00:08」「O 00:12」はルーラーだけ。ツールバーに「範囲 4 秒」 |
| ⇧Delete（範囲） | 本編 `main@0+240 main-split@240+240`、テロップ / B ロール / 効果音は 8〜12 秒が消え、後ろ（15 秒）の各 1 本が `at` 450 → 330（4 秒前へ）。BGM `bgm@0+600` 不変。リンク音声は `main-audio-split → main-split` に付け替わる。字幕チップ「後ろの字幕」left 71.43% → 52.38%（15 → 11 秒）、範囲内の行は消える。範囲は解除・再生ヘッドは 8 秒。Cmd+Z 1 手で byte 一致 |
| Delete（範囲） | 範囲内が消えて隙間が残る（`main-split@360`、後ろの `at` 450 は不変）。範囲は解除 |
| 隙間クリック → Delete | 隙間に選択の枠（破線）が出る。インスペクターは開かない。Delete で `main-split@360 → 240` ほか同量詰まる。Cmd+Z で隙間の状態へ byte 一致 |
| 隙間の右クリック | 「あいだを生成」「この隙間を詰める (Delete)」。「あいだを生成」→ 右パネルに「すき間 · 4.0 秒」の枠（前後のコマ・作る）が出る。edit.json は変わらない |
| クリップ（B ロール 7〜13 秒）を選んで ⇧Delete | そのクリップが消え、同じトラックの後ろ `broll-later` 450 → 270（6 秒前へ）。本編・リンク音声・BGM は不変。テロップ / 効果音の後ろの 1 本は前のクリップ（7〜13 秒）にぶつかって 450 → 390 で止まり、ステータスバーに「2 件は前のクリップにぶつかって寄せきれませんでした」 |
| 10 秒で Q | 前の切れ目 7 秒から 10 秒までが消えて詰まる（`main@0+210 main-split@210+300`、後ろ 450 → 360）。再生ヘッド 7 秒 |
| 10 秒で W | 10 秒から次の切れ目 13 秒までが消えて詰まる（`main@0+300 main-split@300+210`、後ろ 450 → 360）。再生ヘッド 10 秒のまま |
| 10 秒で ⌘B（選択なし） | 本編・リンク音声・テロップ・B ロール・効果音が 300 フレームで割れる。BGM は割れない（固定）。左パネルは畳んだまま / 開いた状態（幅 275px）でも開閉しない |
| B ロールを選んで ⌘B | B ロールだけ割れる（他は不変） |
| 分割ツール（B）で本編をクリック | `main@0+149 main-split@149+451` と `main-audio@0+149 → main` / `main-audio-split → main-split`（リンク音声も同じフレームで割れる） |
| クリップの右クリック | 「分割」「再生ヘッドで分割 (⌘B)」…「詰めて消す (⇧Delete)」「隙間を残して消す (Delete)」「削除」 |
| 自動で詰める | ON（`aria-pressed=true`）で Delete → 詰まる（`broll-later` 450 → 270）。OFF で Delete → 隙間が残る（450 のまま）。ON のまま再起動 → ON、OFF にして再起動 → OFF |
| ルーラーのドラッグ / クリック | 8 → 12 秒のドラッグで範囲 8〜12 秒。クリックだけならシークのみ（範囲なし）。Esc / ⌥X で範囲解除。選択なしで X（3 秒）→ 本編の 0〜20 秒、B ロール選択で X → 7〜13 秒 |
| テキスト入力中に i o x q w | 入力欄に「ioxqw」が入るだけ。edit.json byte 一致・範囲と再生ヘッドは不変 |
| 回帰 | B / V でツール切替、M でスナップ切替（true → false → true）、通常の Delete は隙間が残る。全段のあと edit.json は基点と byte 一致 |
| ショートカット設定画面 | 新しい 9 個（範囲の入口を打つ・範囲の出口を打つ・クリップの長さを範囲にする・範囲を解除・詰めて消す・自動で詰める・前の切れ目まで詰める・次の切れ目まで詰める・再生ヘッドで分割）が並ぶ。「重なり」表示は既存の行だけで、新しい行には出ない |
