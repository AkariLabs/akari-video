# 証跡: タイムラインの縦幅を返す + 両端をつまめる横 / 縦ズームバー・100% より引く・端ドラッグの自動送り（2026-10-06-tl-chrome-zoom）

検証はラッパーが実施（実機 = 専用の CDP ポート 9462・一時ディレクトリの `--user-data-dir` / `THEIA_CONFIG_DIR` / `AKARI_HOME`・一時 workspace）。
BEFORE は基点のビルド（本タスクの変更前）、AFTER は本タスクのビルド。ウィンドウは 1440×900（CSS px）、左右のパネルを畳んだ同じ配置。
記録物（JSON・PNG）はリポの外に置き、ここには再現用のスクリプトだけを置く。

## fixture と手順

- `scripts/gen-fixture.mjs`: 12 秒のベース映像（Base）+ 2 本目の映像トラック V2（4 秒の素材を 2 秒目に 1 本）+ 字幕 4 行 + 音のトラック A1（効果音 3 秒を 1 秒目に 1 本）。素材は ffmpeg で作る（L1 専用）
- `scripts/measure-chrome.mjs`: タイムラインの入った下側パネルの縦方向の内訳（タブ行・ツールバー・横バー・足元行・トラックの見えている領域 `stripScroll`）を採る
- `scripts/interact.mjs`: 実マウス（CDP `Input.dispatchMouseEvent`）で次を順に行い、表示範囲（`viewStart` / 表示幅）・% 表示・edit.json・行の高さを採る
  - ルーラーのクリック → 最下段のステータスバーの報告が出て消えるまでの時間
  - 横バーの右ハンドル / 左ハンドル / 本体のドラッグ、ダブルクリック
  - スライダー最小・Ctrl+ホイールで 10%、終わりより先の別背景、そこへのクリップ移動 → % ボタン → Cmd+Z
  - 縦バーの下ハンドルを上へ → 再読み込み → ダブルクリック
  - 300% 付近でクリップを掴み、帯の右端から 10px で 1.2 秒保持 → 離す → Cmd+Z
  - 回帰（Ctrl+ホイール・% ボタン・トラック境目・トリム・分割ツール・スナップ・素材 D&D、各 Cmd+Z）
  - 補足（右ハンドルを土台の右端より先へ・再生ヘッドのスクラブ / 素材ドラッグの端送り・警告の色と表示時間）
- `scripts/launch.mjs`: 起動して止めておく（手で観察するとき用。止めるのは表示された PID だけ）
