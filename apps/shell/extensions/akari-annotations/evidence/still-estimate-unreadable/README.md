# 静止画の見積もり復旧 L1

このスクリプトは、ビルド済みの開発用 Electron 環境で画像パネルを検査する。料金表の名前を一時的に変え、fal を選び、指示文の入力イベント前後で作成ボタンが押せないことを確認する。料金表を元に戻して **状態を確かめ直す** を押す。生成は開始しない。

事前に依存パッケージをインストールし、shell extensions をビルドする。出力先には `evidence/` の外、隔離用にはリポジトリの外のディレクトリを指定する。

Electron の起動フラグで、ウィンドウが覆われていても描画とタイマーを動かし、Theia の preload が完了するようにする。

```sh
node apps/shell/extensions/akari-annotations/evidence/still-estimate-unreadable/l1.mjs --out=<output-dir> --iso=<isolation-dir> --port=22491 --repo=<repository>
```

スクリプトは `--out` に `results.json` と 6 枚のスクリーンショット（各状態のウィンドウ全体とインスペクターの切り抜き）を書く。結果では、fal の手段行と作成ボタンの近くに失敗理由が出ること、「確認中」の文言が残らないこと、実際の指示文入力イベント後もボタンが押せないことを確認する。また、読み直しボタンを押すと Electron の再起動なしで `$0.xxx` の見積もりが戻り、作成ボタンが押せることを確認する。元の料金表を復元したかどうかも記録する。
