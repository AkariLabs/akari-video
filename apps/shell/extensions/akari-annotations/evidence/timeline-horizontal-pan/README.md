# evidence: timeline-horizontal-pan（タイムラインの横スクロール／パン）

L1 検証（production ビルド + 生 CDP 実操作）の証跡。フィクスチャは既存のズーム機能検証
（cuts 3個・字幕6件・オーバーレイ1件、実素材26.3秒、`output.fps=30`）と同一のものを流用。

検証環境: production ビルド（`npm run build`、0 errors）の Electron を隔離
user-data-dir（`THEIA_CONFIG_DIR` / `--user-data-dir` 併用）+ `--remote-debugging-port` で
起動し、`playwright-core` の `chromium.connectOverCDP` で実際の wheel・pointerdown/
pointermove/pointerup イベントをディスパッチして操作した（座標はレンダリング後の DOM
`getBoundingClientRect()` の実測値）。

## 割り当てた入力（受け入れ条件2）

- **横スクロールバー**: タイムライン下部の専用トラック + つまみ（`pointerdown`/`pointermove`/
  `pointerup` でドラッグ）。トラックの余白クリックでもその位置を中心にページ移動する。
- **トラックパッド横スクロール**: `strip` 上の `wheel`（ctrl 無し）で `deltaX` が `deltaY` 以上の
  とき、そのまま `deltaX` を横パンに使う。`shift+wheel`（`deltaX` が小さい環境向けの保険）にも
  対応。ctrl 無し・縦 wheel 主導（shift 無し）は `preventDefault` せず素通りし、既存の縦スクロール
  等を壊さない。ctrl+wheel は既存のズームのまま変更なし。

## 受け入れ条件ごとの実測

### L1-1: 横スクロールバー出現・ドラッグでパン

- 全体表示ではスクロールバー `display:none`（01）。ctrl+wheel でズームすると
  `display:block` になり、つまみ幅 = `visibleDuration/totalDuration`（実測 8.78%）、
  位置 = `viewStart/totalDuration`（実測 45.61%）で表示される（02）。
- つまみをトラック幅の25%分ドラッグすると、つまみの位置(%)が `45.61% → 70.61%` に
  移動し、ルーラーの可視時刻域が `00:12.5〜14.0` → `00:19.0〜21.0` に変化（クリップ表示も
  C2→C3 に切り替わり、字幕テキストも追従）。ドラッグ前後でルーラーラベルが完全に異なる
  ことを実測（03）。

### L1-2: トラックパッド横スクロール（`deltaX` 主導の wheel）

- ctrl 無し・`deltaX=150〜220`・`deltaY=0` の wheel イベントを6回ディスパッチしたところ、
  つまみ位置が `70.61% → 83.43%` にさらに進み、ルーラーが `00:19.0〜21.0` →
  `00:22.5〜24.0` に変化（04）。ctrl 無し・純粋な縦 wheel（deltaY 主導・shift 無し）は
  本タスクのコードパスで `preventDefault` されないことをソースの分岐条件で確認済み
  （非退行節も参照）。

### L1-3: パン中の同期（クリップ/字幕/プレイヘッドがズレない）

- ルーラーラベル2点から `viewStart`/`visibleDuration` を逆算し、既知の cuts 座標
  （`[0,7.5] [9,17] [19,26]`）から予測したクリップの `left%`/`width%` と実際の DOM 値を
  クロスチェック。パン前・パン後のどちらも全クリップで誤差0（完全一致）を確認（15/16、
  詳細な実測値は `sync-detail.json` 相当のログに記録）。
- ルーラー・クリップ・字幕はいずれも同一の `percent()`（`viewStart`/`visibleDuration` 基準）
  から算出されるため、上記の実測はこの一箇所を変えるだけで全描画要素が追従する設計を
  裏付ける。

### L1-4: 全体表示ではスクロールバーが非表示

- 初期状態（01）・ズームからスライダーで全体表示に戻した状態（06）のどちらも
  `display:none` を確認。

### 非退行（6種・契約の最低5種を上回る実測）

| 操作 | 実測 diff |
|---|---|
| トリム | `cuts[0].out: 7.5 → 8.85`（他は不変）→ undo で `8.85 → 7.5` に復元 |
| 並べ替え | `cuts` 配列順 `[{0,7.5},{9,17},{19,26}] → [{9,17},{0,7.5},{19,26}]` → undo で元の順序に復元 |
| 字幕ずらし | `c-0002` の `start: 5.22→4.49` / `end: 8.28→7.55`（他の字幕は不変）→ undo で `5.22`/`8.28` に復元 |
| Esc キャンセル | ドラッグ中（ゴースト表示済み）に Esc → `edit.json` の内容がバイト単位で無変化 |
| クリックシーク | タイムライン背景クリックでフッターに選択時刻（例: `00:00:13.260 を選択しました。`）が表示 |

いずれも本タスクのパン機能追加によって既存の挙動が変化していないことを確認。
