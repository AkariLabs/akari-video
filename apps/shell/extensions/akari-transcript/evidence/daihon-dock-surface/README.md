# 台本の操作面（右クリック = 操作・下端のドック = 編集面）— L1 証跡

台本で「操作」と「見た目の編集」の置き場を分けた変更の実機観測。
行か置いた文字の札をクリックすると、行リストの下端にドック（高さ固定・中身だけスクロール・タブ）が出る。
右クリックはその要素への操作だけ。行の下に出していたピッカー（テンプレ・強調）は無くした。

## 再現

```bash
node scripts/gen-fixture.mjs <fixture dir>           # 話した言葉 8 行（語の時刻つき）+ 置いた文字 2 本
node scripts/l1-before.mjs <fixture dir> --port=9473 # 変更前ビルドで実行
node scripts/l1-after.mjs  <fixture dir> --port=9473 # 変更後ビルドで実行（--prefix=rerun で再走）
```

負荷の高いマシンでは `AKARI_CDP_TIMEOUT_MS=60000 AKARI_L1_LAUNCH_MS=600000` を付ける。
`l1-after.mjs` は書き込みのたびに fixture を変えるので、走らせる前に毎回 `gen-fixture.mjs` で作り直す。
`scripts/cdp-lib.mjs`・`l1-lib.mjs` は `daihon-attachments` の証跡と同じもの。

## BEFORE（変更前ビルド・`results-before.json`・`before-*.png`）

| 操作 | どこに出るか | 行の top のずれ |
|---|---|---|
| 行の余白をクリック | 何も出ない（シークだけ） | 0px |
| 行を Shift+クリック | 行リストの下に選択バー（テンプレ適用・結合・カット 等）。行リストの高さが 703 → 567.5px に縮む | 0px |
| ヘッダーの「🎨 テンプレ」 | 浮きポップ（fixed・284×478.5px）に 13 枚。「字幕テンプレ — 適用先: 選択 1 行」 | 0px |
| 単語をクリック | 浮きバー（▶ / 🎨 テンプレ / ✨ 強調 / ✂ / ＋ 語 / ✕）→「テンプレ」で単語のテンプレ 5 枚の浮きポップ | 0px |
| 行の ⚙ | 浮きポップ「字幕設定」（スタイル・表示タイミング・アニメ・インスペクターで開く） | 0px |
| 単語を右クリック | 語メニュー（再生・直す・辞書・カット・Freeze・**強調のプリセット 5 種・強調を外す**・挿入・改行・分割・結合・マーク） | 0px |
| 置いた文字の札をクリック | 行リストの下に範囲エディタのカード（高さ 108.5px・行リストが 594.5px に縮む）: 「T 今日の予定 / 6 行目 〜 7 行目（0:20.00 〜 0:27.19）/ 全部の行に・文字を編集・削除・閉じる / 範囲は左の棒の両端を引いて変えます」 | 0px |
| 札を右クリック | 浮きポップ: 全部の行に / 文字を編集 / 削除 | 0px |

行の下に展開するピッカーはこのビルドの時点で既に無く（どれも fixed の浮きポップ）、行の top のずれはどの操作でも 0px だった。

## AFTER（変更後ビルド・`results-after.json` / 同じビルドの再走 `results-rerun.json`（スクショは after 分のみ残す）・どちらも全 13 検査 pass）

パネル 835px（台本パネルの幅 578px・窓 1440×900）での実測:

| 検査 | 結果 |
|---|---|
| 1 行のクリック | ドックが開く。高さ 418px = パネルの 0.501。下端 712.5 = 選択バーの上端（選択バー・フッターは覆わない）。全行の top のずれ 0px。タブ = テンプレ / 見た目 / アニメ / 強調 / 時刻 |
| 2 タブ切替 | テンプレ・見た目・アニメ・強調・時刻すべて 418px（差 0px）。テンプレタブは中身 355px > 見えている 344px でドックの中だけスクロール（overflow-y:auto）。行の top のずれ 0px |
| 3 テンプレ | カテゴリ = すべて / 字幕 / 強調 / 見出し / 価格 / バラエティ、カード 13 枚（先頭「テンプレなし」）。「ニュース風」→ c-0003 の `style_preset` = `subtitle-news`（他の行は不変）→ Cmd+Z 1 手で captions.json が byte 一致 |
| 4 見た目 | 文字色 #facc15 → c-0003 に `text_style.color` = `#facc15` → Cmd+Z 1 手で byte 一致 |
| 5 複数行 | 2 行選択でドックの見出し「2 行を編集」→ バラエティ → 2 行とも `subtitle-variety` → Cmd+Z 1 手で byte 一致 |
| 6 単語のクリック | 強調タブが「挽きたてが」で開く（浮きポップ 0 件・行の top のずれ 0px）→ ネオン → `emphasis_words` に 1 件 → Cmd+Z 1 手で byte 一致 |
| 7 もっと細かく | `akari.preview.captionSelected` が `c-0003` で飛び、インスペクターの見出しが「豆は挽きたてが一番おいしい 00:08.0 – 00:11.2 · 字幕」 |
| 8 右クリック | 行 = ここで切る / 分割 / 次の行と結合 / 下に行を足す / 削除（ドックは開かない）。単語 = 語メニューから強調のプリセットと「強調を外す」が抜けた（操作だけ）。札 = 全部の行に / 削除。行リストの中にピッカー 0 件 |
| 8b 分割 | 行メニューの「分割」で既存の分割モードに入る（境界の印 3 個・captions.json は不変） |
| 9 札のクリック | タブ = 文字 / テンプレ / 見た目 / アニメ。4 タブとも 418px = 行のときと同じ。行の top のずれ 0px |
| 10 閉じる | Esc（行リストにフォーカス）/ ✕ / 行リストの何もない所のクリック、の 3 通りとも閉じる |
| 11 高さの記憶 | つまみを 120px 上へ → 418 → 532px（`localStorage` に `532px`、タブを替えても 532px）→ 同じプロファイルで再起動 → 532px |

見た目タブの項目: 文字色（6 色）/ 座布団の色（なし + 6 色）/ 大きさ（28・38・56・72）/ 字間（-0.05・0・0.12 em）/ 縁取り（なし・1.5・3 px）+「もっと細かく → インスペクターで開く」。
座布団の幅（文字に合わせる / 画面幅）は出していない: 字幕のスタイル書き込み API（`setCaptionTextStyle` の patch）に幅の項目が無いため（`background.mode` は「行ごと / まとめて」で幅ではない）。
