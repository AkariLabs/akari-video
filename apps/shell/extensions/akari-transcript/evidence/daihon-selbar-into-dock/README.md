# 台本の選択バーを下端のドックへ統合（ドックの下に残る帯をなくす）— L1 証跡

行を選ぶとドックのさらに下に出ていた選択バー（`.akari-daihon-selbar`）を無くし、
選択の情報はドックのヘッダーへ、選択バーのボタンは行の右クリックメニュー・ドックのテンプレタブ・ドックの ✕ / Esc へ移した変更の実機観測。

## 再現

```bash
node scripts/gen-fixture.mjs <fixture dir>             # 話した言葉 8 行（語の時刻つき）+ 置いた文字 2 本（daihon-dock-surface と同じ中身）
node scripts/l1-before.mjs <fixture dir> --port=9475   # 変更前ビルドで実行
node scripts/l1-after.mjs  <fixture dir> --port=9475   # 変更後ビルドで実行（--prefix=rerun で再走）
```

負荷の高いマシンでは `AKARI_CDP_TIMEOUT_MS=60000 AKARI_L1_LAUNCH_MS=600000` を付ける。
`l1-after.mjs` は書き込みのたびに fixture を変えるので、走らせる前に毎回 `gen-fixture.mjs` で作り直す。
`scripts/cdp-lib.mjs`・`l1-lib.mjs` は `daihon-dock-surface` の証跡と同じもの。測る式は `scripts/l1-measure.mjs`（BEFORE / AFTER 共通）。
行の選択は c-0005 をクリック → c-0003 を Shift+クリック（3 行 = c-0003〜c-0005）。

## BEFORE（変更前ビルド・`results-before.json`・`before-*.png`）

窓 1440×900・台本パネルの幅 578px での実測:

| 選択 | 選択バー（top〜bottom / 高さ） | 選択数の文言 | ドック（top〜bottom / 高さ） | 位置関係 |
|---|---|---|---|---|
| 1 行 | 712.5〜848 / **135.5px** | 「1 行選択（Shift=範囲 / ⌘=追加 / ドラッグ=まとめて）」が幅 44px に押し込まれ **9 行に折れる** | 294.5〜712.5 / 418px | ドックの下端 712.5 = 選択バーの上端。選択バーの下端 848 = フッターの上端。ドックの下に 135.5px の帯 |
| 3 行 | 695〜848 / **153px** | 「3 行選択（…）」が **10 行に折れる** | 277〜695 / 418px | ドックの下に 153px の帯。ドックの見出し「3 行を編集」 |

選択バーのボタン: 🎨 テンプレ適用 / ⧉ 選択行を結合 / 次の行と結合 / 発話にぴったり / ✂ 選択行をカット / ✕ 解除（各 1 行・高さ 19〜22.5px）。
3 行選択のまま行を右クリック → メニューは ここで切る / 分割 / 次の行と結合 / 下に行を足す / 削除 で、選択は右クリックした 1 行（c-0004）に置き換わる。

## AFTER（変更後ビルド・`results-after.json` / 同じビルドの再走 `results-rerun.json`（スクショは after 分のみ残す）・どちらも全 9 検査 pass）

| 検査 | 結果 |
|---|---|
| 1 1 行の選択 | `.akari-daihon-selbar` **0 個**・ドックとフッターの間の帯 0 個。ドック 430〜848 / 418px（下端 848 = フッターの上端）。ヘッダー = 「蒸らしは30 秒くらい」+ 説明「Shift=範囲 / ⌘=追加」（10px・muted・nowrap・それぞれ 1 行）。ヘッダーの高さ 31px（BEFORE と同じ） |
| 2 3 行の選択 | `.akari-daihon-selbar` 0 個・帯 0 個。ヘッダー「**3 行を選択中**」+ 説明。ドックの高さ 418px（1 行のときと同じ）・タブ = テンプレ / 見た目 / アニメ / 強調 / 時刻（BEFORE と同じ） |
| 3 3 行選択のまま右クリック | メニュー = 選択行をカット / 選択行を結合 / 発話にぴったり。選択は c-0003・c-0004・c-0005 のまま |
| 4 右クリック「選択行を結合」 | captions.json 10 → 8 件（台本の行 8 → 6）・c-0003 = 「豆は挽きたてが一番おいしいお湯は少し冷ましてから注ぎます蒸らしは30 秒くらい」8.0〜19.2 → Cmd+Z 1 手で captions.json が byte 一致・行 8 に戻る |
| 5 右クリック「発話にぴったり」 | 3 行とも `display_timing` = `speech-tight`（他の行は不変）→ Cmd+Z 1 手で byte 一致 |
| 6 右クリック「選択行をカット」 | edit.json の main が 4 片（7.97〜11.23 / 11.97〜15.23 / 15.97〜19.23 秒を除去）・カットの札 3 枚 → 札の「↩ 戻す」1 手で edit.json が byte 一致 |
| 7 ドックのテンプレタブで 3 行に一括適用 | 3 行とも `style_preset` = `subtitle-variety` → Cmd+Z 1 手で byte 一致 |
| 8 1 行の右クリック | ここで切る / 分割 / 次の行と結合 / 発話にぴったり / 下に行を足す / 削除（旧選択バーの 1 行向け操作も右クリックに残る） |
| 9 解除 | ドックの ✕ → ドックが閉じ選択 0 行。Esc（行リストにフォーカス）→ 同じく閉じて選択 0 行 |

終了時の captions.json・edit.json は fixture と byte 一致（`final`）。

映像ごとカットの取り消しは台本の履歴（Cmd+Z）ではなくカットの札の「↩ 戻す」が既存の経路（旧選択バーの「✂ 選択行をカット」も同じ `cutSelectedRows` → `applyCutRanges`。本変更で経路は変えていない）。検査 6 の `cmdZChangedEdit: false` はその観測。

## 旧選択バーのボタンの行き先

| 旧ボタン | 行き先 |
|---|---|
| 🎨 テンプレ適用 | ドックのテンプレタブ（既存） |
| ⧉ 選択行を結合 | 行の右クリック「選択行を結合」（2 行以上のとき。結合できない選択は disabled + 理由） |
| 次の行と結合 | 行の右クリック「次の行と結合」（既存項目・1 行のとき） |
| 発話にぴったり | 行の右クリック「発話にぴったり」 |
| ✂ 選択行をカット | 行の右クリックのカット（既存の「ここで切る」と 1 つにまとめた。1 行 =「ここで切る」/ 複数 =「選択行をカット」） |
| ✕ 解除 | ドックの ✕ / Esc（行のドックを閉じると選択も外れる） |
