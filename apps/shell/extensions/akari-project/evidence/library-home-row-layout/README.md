# ライブラリのホーム一覧の行レイアウト — L1 証跡

## 採取方法

- BEFORE = 変更前の HEAD（`13d8784a`）を `git archive` で `/tmp/lhrl-before` に展開してビルドしたもの。AFTER = 本ブランチのビルド
- Electron を直接起動（`AKARI_HOME` / `THEIA_CONFIG_DIR` / `--user-data-dir` は `/tmp/lhrl-l1/` 配下、CDP ポート 9412、ウィンドウ 1120×668）。
  ワークスペースは `templates/project-default` の複製。カタログは本番
- `scripts/measure.mjs <label> [幅]` — ライブラリ面のホームを開き、必要なら左右スプリッターを実マウスでドラッグして左パネルを指定幅にし、
  全カテゴリ行（マイの 3 タイルを除く 17 行）の アイコン / タイトル / 説明 / 件数 の矩形を実測して `<label>.json` と `<label>.png`（左パネル部分）を書く
- `scripts/regress.mjs <prefix>`（`Q=<検索語>`）— 「近日」行までスクロールした画面、行の実クリック → カテゴリページ、検索結果の行、マイの 3 タイルを記録
- 幅: 新規 user-data での既定幅（左パネル 213.91px）と 259.53px（≒260）と 360.42px。既定幅が 260 より狭かったため、広い側として 360 も採った
