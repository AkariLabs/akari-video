# Scene3D 素材 — 3D モデル + 表示断片 / ベイクレシピ

## 素材

- [vintage-camera-turntable](./vintage-camera-turntable/meta.json) — ヴィンテージカメラの周回ヒーローショットを Blender ヘッドレスで mp4 クリップに焼くベイクレシピ（CC0 / requires: blender）。
- [smartphone-mockup](./smartphone-mockup/meta.json) — 現代的な縁なしスクリーンのスマホ実機モデルの画面に静止画/動画を差し込んでヒーローショットに焼くベイクレシピ。media 型ツマミ（screen_src）の実証第一号（CC0 / requires: blender）。

## このカテゴリに入るもの

スマートフォンや製品のモックアップ、固有形状のモデルなど、モデリング・質感・リグの生成コストが高い 3D 素材。実体は表示断片（fragment.html、経路 A）またはベイクレシピ（scene.py、経路 B）のどちらか一方。

## このカテゴリに入らないもの

CSS の疑似立体表現、単純な箱・平面、自然言語から短時間で再生成できる汎用形状。
