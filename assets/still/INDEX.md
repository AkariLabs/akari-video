# Still 素材 — 時間を持たない HTML シート

スクリーンショットで画像に焼く HTML シートです。オーバーレイと違い `data-start` /
`data-duration` を持たず、決定的なスクショで PNG になります。背景（実フレーム or 生成画像）を
差し替えて再利用する前提の文字組レイヤーを収録します。

2026-07-29 にカテゴリ名を `thumbnail`（主題）から `still`（配布物の形）へ変更しました。
サムネイル用途は tags の `thumbnail` で引きます。

## 素材

エントリはまだありません。[harvest-asset](../../skills/harvest-asset/SKILL.md) スキルで収穫します。

## このカテゴリに入るもの

サムネイル構図テンプレ、静止の告知シート、書き出して画像として使う HTML 文字組。

## このカテゴリに入らないもの

時間つきで映像に重ねるもの（→ [overlay](../overlay/INDEX.md)）。
