# 図形プリセット

`index.jsonl` は図形 219 種（15 カテゴリ）、ライン 45 種、漫画の吹き出し 12 種の計 276 件を収めます。図形を置くときは ID を参照し続けず、`d`・`vb`・`defaults` を edit.json に値でコピーします。

| カテゴリ | 件数 |
| --- | ---: |
| 基本の図形 | 15 |
| 多角形 | 9 |
| スター | 12 |
| 矢印 | 17 |
| フローチャート | 16 |
| 吹き出し | 10 |
| 雲 | 6 |
| ハート | 12 |
| 横断幕・垂れ幕 | 9 |
| 雫 | 4 |
| 歯車 | 8 |
| 四角い星・アスタリスク | 8 |
| 有機的 | 37 |
| 波線 | 6 |
| 抽象的 | 50 |
| ライン | 45 |
| 漫画の吹き出し | 12 |

`node presets/shapes/generate.mjs` で決定論的に再生成します。`shape-catalog.mjs` はパスの生成関数で、出力は絶対座標の `M/L/C/Z` に統一します。角丸の見本には `rounded_from` を併記し、配置時は基底の形と丸みをコピーします。
