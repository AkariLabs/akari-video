## 4. 文字カード（`--placeholder`）の実測

- 既定解決の ffmpeg（この作業機では PATH の Homebrew ffmpeg）は **libfreetype 無しで drawtext を持たない**。
  初回実装ではここで 1 枚も作れず「完了 0 枚・スキップ 3 枚」になっていた（ラッパー検証で検出）。
  drawtext 失敗時に `-vf` 無しで作り直す劣化経路を足し、**完了 3 枚・失敗 0 枚（exit 0）**へ回復
  （WARN: `drawtext が使えないため文字カード <id> は文字なしの単色カードにしました`）
- 同梱 vendor ffmpeg（`packages/media-bin/vendor/darwin-arm64/ffmpeg`）を `AKARI_FFMPEG_BIN` で指すと
  drawtext が効き、`<id>` と `name` を中央に描いた 1920x1080 の文字カードになる（目視確認済み）
- 同じ spec で 2 回目を走らせると `WARN: gen-<id> は既にあるため上書きしません` で
  **完了 0 枚・スキップ 3 枚**（既存クリップを上書きしない）
