The still-image MAD ceiling is 128 because the 240×160 still covers two thirds of the 320×180 frame and only RGB differs: `(240×160)/(320×180) × 3/4 × 255 = 127.5`, rounded up. The generated v2 render receipt confirms that `still.png` is absent from the layers command, so this ceiling bounds the render-cut-side projection omission rather than relaxing the engine comparison after observing a failure.

## Interpretation

Engine-side error rows: **0**. Every known-difference reason names the concrete ffmpeg/render-path operation active in that isolated window; classes are not accepted merely because a reason string exists.

Blend modes `screen` and `multiply` are verified by two sample times each. `add`, `difference`, `darken`, `lighten`, `overlay`, `hardlight`, and `softlight` are implemented from the ffmpeg-compatible component formulas but remain **unverified** in this fixture.
